# 操作限时挡位 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 房主可在大厅开局前与对局内设置「操作限时」挡位（现状 / 15s / 30s / 60s / 不限时），决定真人玩家每个操作环节发呆多久后由系统托管；改挡位立即生效并重计时。

**Architecture:** 新增 `GameSettings` 配置对象（目前只有 `timeout_tier` 一个字段）承载房主配置，`net.gd` 持有一份供大厅写、对局读；对局内所有等待环节改走统一的 `game.gd:_await_turn_window()` 原语，挡位随 `s_state` 快照下发（不新增 RPC），客户端只读展示。四个原超时常量降级为「现状」档的定义值，默认行为与今天完全一致。

**Tech Stack:** Godot 4.6 / GDScript（Tab 缩进、中文注释）；测试是 `SceneTree` 脚本，`godot --headless --path . --script tests/xxx.gd`。

**Spec:** `docs/gameplay/开局设置.md` §三之一（本次唯一实现切片）

## Global Constraints

- **Godot 路径因机器而异**：`$G = "D:\Godot\Godot_v4.6.2-stable_win64_console.exe"`（用 `_console.exe`，否则看不到 print）。改完代码先跑 `& $G --headless --path . --script tests/load_all.gd` 做静态加载检查。
- **房主权威**：玩法逻辑只在房主侧计算；客户端只发 `c_*` 请求 + 渲染，绝不直接改 `hp/htiles`。
- **状态同步铁律**：任何「全员可见」的状态必须进 `_broadcast_state`（`s_state` 快照）。
- **哨兵值**：`GameData.NO_OWNER = -100`，不要用 -1。
- **风格**：GDScript、Tab 缩进、中文注释；数据/工具类用 `class_name`。
- **默认行为不可变**：「现状」档必须等于今天的常量（掷轮 `GameData.ROLL_TIMEOUT 35s`、决策 `GameData.PROMPT_TIMEOUT 25s`、道具 `ItemData.ITEM_TIMEOUT 12s`、逛店 `ItemData.SHOP_TIMEOUT 20s`、黑市 `ItemData.BLACK_TIMEOUT 20s`）。
- **不持久化**：不写 `user://settings.cfg`，每局重设。
- **不主动提交**（AGENTS §六）：每个任务末尾的 commit 步骤必须先征得用户明确同意才执行；未获同意时把改动留在工作区，继续下一个任务。
- **文档同步**：机制/数值改动 → `docs/gameplay/*`；协议改动 → `docs/dev/*`。

`scripts/game.gd`，把 `func _wait(sec: float)` 附近补上原语：

```gdscript
## 等一个环节的操作窗口。返回 true = 真超时（该自动托管）；false = 环节已结束。
## 挡位变化（_timeout_rev 变）会按新秒数重计时；挡位为「不限时」则不托管。
## on_arm(sec) 在每次窗口（重）开始时调一次——弹窗倒计时条据此重启。
func _await_turn_window(kind: String, alive: Callable, on_arm := Callable()) -> bool:
	while running and alive.call():
		var rev := _timeout_rev
		var sec := GameSettings.turn_seconds(_settings.timeout_tier, kind)
		if on_arm.is_valid():
			on_arm.call(sec)
		if sec <= 0.0:
			# 不限时：轮询等环节结束或挡位变化（0.25 秒一次，开销可忽略）
			while running and alive.call() and _timeout_rev == rev:
				await _wait(0.25)
			continue
		await _wait(sec)
		if not (running and alive.call()):
			return false
		if _timeout_rev != rev:
			continue
		return true
	return false
```
