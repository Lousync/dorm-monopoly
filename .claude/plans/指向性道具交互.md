# 指向性道具交互返工

> 2026-10-02 拍板：**点棋盘玩家卡直选** + **两段式手选地块**（强拆令/抄家队）。

## 现状问题
- 选玩家：只有居中弹窗列表，不能点棋盘座位卡；无 Esc 取消；无「正在选目标」高亮。
- 选地块（快递直达）：只打一行日志，无高亮、无按钮取消、右键取消未实现。
- 强拆令/抄家队：选完玩家后 engine 随机挑一块地，与「指定一块地」不符。
- 机器人遇到点地类道具直接跳过。

## 目标交互
1. 选玩家：高亮可选座位卡（世界坐标），点卡即选；不可选者不高亮。
2. 选地块：高亮可选格子，点格即选。
3. 两段式（`then == "own_prop"`）：选玩家 → 高亮其名下地皮 → 点一块执行。
4. 取消：Esc / 右键单击 / 屏幕提示条上的「取消」按钮；拖拽平移不误触。
5. 屏幕提示条：显示「选择目标玩家 / 点选他的一块地 / 选择目标格」+ 取消。

## 数据
- `item_data.gd`：`强拆令`/`抄家队` 加 `"then": "own_prop"`；抄家队卡面去掉「随机」。
- `交换课表` 维持随机（卡面如此）。

## 协议
- `c_use_item(slot, arg, arg2=-1)` / `_use_item(peer, slot, arg, arg2=-1)` / `_apply_item_effect(p, it, arg, arg2=-1)`。
  - `arg` = 玩家 peer（两段式时）或格 idx（快递直达）；`arg2` = 两段式的地皮格 idx。

## 触点
- `board_view.gd`：`set_select_peers/set_select_tiles/clear_select` + 高亮叠层；`cancel_clicked` 信号（右键未平移时）。
- `game.gd`：目标状态机 `_tgt_*`；`_on_seat_clicked`/`_on_tile_clicked` 路由；`_cancel_target`。
- `table_hud.gd`：座位点击改走 `_on_seat_clicked`；新增目标提示条；移除旧 `target_picker`。
- 文档：`道具系统.md`、`道具图鉴.md`、`开发台账.md`。
