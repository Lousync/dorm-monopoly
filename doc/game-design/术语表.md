# 术语表

> 全局共用语义——这些词在本项目里有**固定含义**，各文档一律按此使用。
> 道具机制见 `道具系统.md`，逐件道具见 `道具图鉴.md`。

| 关键词 | 定义 |
|---|---|
| **发现** | 三选一：弹三张卡选择；真人私下收到自己的三选项（私密 RPC），bot 按策略自动选 |
| **休眠** | 你的回合不能进行任何操作，**被动照常生效**；等价「强制保守托管」：系统代掷、买地一律拒绝、商店自动离开、赌场自动抽牌（小黑屋即休眠） |
| **跳过回合** | 整回合被压制，**被动也不享受**（转轮 0 原地待命、宿委会反省属此类） |
| **冷却** | 每件道具**各自**的禁用回合数，默认 = 该道具的体力消耗；冷却跟着道具实例走（被交换时带走） |
| **唯一性** | 被动道具与橙色道具整局唯一：铺货 / 礼物 / 发现时，已被持有的唯一道具从可获取池排除；**货架在售同样占用唯一性**；丢弃 / 破产回池 |
| **debuff / 中性 / 无标签** | 每个效果人工标注：debuff 可被香皂免疫；中性（租金 / 购买 / 赌注 / 道具消耗）永不免疫；科技无标签、香皂无效 |
| **科技** | 开局三选一的强化（**原称「畸变」**）：发车前每人独立发现三张科技、选一张，结果全员公开；效果无 buff/debuff 标签 |
| **畸变** | 开启后由房主在某些回合开始时触发的**全场事件**（**原称「特殊事件」**），如「诚信考试」；不利项是 debuff |
