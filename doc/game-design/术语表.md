# 术语表

> 全局共用语义——这些词在本项目里有**固定含义**，各文档一律按此使用。
> 道具机制见 `道具系统.md`，逐件道具见 `道具图鉴.md`。

| 关键词 | 定义 |
|---|---|
| **发现** | 三选一：弹三张卡选择；真人私下收到自己的三选项（私密 RPC），bot 按策略自动选 |
| **休眠** | 你的回合不能进行任何操作，**被动照常生效**；等价「强制保守托管」：系统代掷、买地一律拒绝、商店自动离开、赌场自动抽牌（小黑屋即休眠） |
| **跳过回合** | 整回合被压制，**被动也不享受**（宿委会反省属此类）。**注意：转到 0 的「原地待命」不是跳过回合**——不能移动，但被动照常结算、也照常进道具阶段 |
| **冷却** | 每件道具**各自**的禁用回合数，逐件独立定值（与体力消耗解耦，2026-10-04 起）；冷却跟着道具实例走（被交换时带走） |
| **唯一性** | 被动道具与**金货**（顶档）整局唯一：铺货 / 礼物 / 发现时，已被持有的唯一道具从可获取池排除；**货架在售同样占用唯一性**；丢弃 / 破产回池。**判定只看道具自己的 `unique` 字段**（唯一来源 `scripts/item_data.gd`），不是按品质一刀切——`二青会酒寒暑`（紫档）就是 `unique: false` 的例外 |
| **品质（道具）** | 道具分四档：**白·普通 / 蓝·稀有 / 紫·史诗 / 金·传说**（`ItemData.QUALITIES`），**没有「绿」**（2026-10-10 道具重构去掉「绿」「橙」两个键）。**别与装修等级混**：装修另有「未装修 / 绿 / 蓝 / 紫 / 金」五级（`GameData.LEVEL_NAMES`），两套系统**各自独立**，只是共用了「蓝 / 紫 / 金」这几个字面 |
| **debuff / 中性 / 无标签** | 每个效果人工标注：debuff 可被香皂免疫；中性（租金 / 购买 / 赌注 / 道具消耗）永不免疫；科技无标签、香皂无效 |
| **科技** | 开局三选一的强化（**早期曾叫「畸变」**，后与全场事件系统**互换了名字**，见下一行）：发车前每人独立发现**同等级**的三张科技、选一张，结果全员公开；分**白银 / 黄金 / 钻石**三档（**白银 20 条（实装 20）/ 黄金 19 / 钻石 20**；2026-10-07 定档），每局**随机定档**（三档等概率、全场同档；2026-10-09 起直接随机抽一档，此前为「掷骰 1~6」映射到三档，分布相同），允许多人重复选同条；效果无 buff/debuff 标签 |
| **畸变** | 开启后由房主在某些回合开始时触发的**全场事件**（**原称「特殊事件」**；「畸变」这个词早期属于科技，两者互换了名字），如「诚信考试」；不利项是 debuff |
| **机会卡** | 三类「**事件卡**」之一，占抽卡的 **85%**：从统一的机会牌堆抽一张（效果字段见 `机会卡.md`） |
| **道具卡** | 三类事件卡之一，占 **10%**：从**可获取池**等概率抽一件道具（唯一池过滤 / 满包作废，口径同失物招领）。**不是**三选一、也不立即使用 |
| **畸变卡** | 三类事件卡之一，占 **5%**：从现有畸变池随机抽一条、**全场立即生效**（见 `畸变.md` §二「例外通道」）。畸变总开关为「关」时这一档作废、5% 并入机会卡（实际 **90 / 10 / 0**） |

> **「事件卡」是机会卡 / 道具卡 / 畸变卡三者的统称**：**只有落在机会格才抽**（棋盘 4 个 `event`
> 格、一律叫「机会」，`only` 字段与「命运」随统一一起退场）。抽卡**先掷类别、再按类别取值**
> （概率写死 `GameData.CHANCE_P` / `CHANCE_ITEM_P` / `CHANCE_AB_P`，不进开局设置）。

## 数值口径

- 数值目前多为占位，各文档在对应位置标「设计待定」；集中清单见各篇末尾的「设计待定」节，
  以及 `development/未完成项-交接.md` 的 **⑦ 数值专场回填**（**「还剩什么」的唯一权威**；
  `development/开发台账.md` §三 自 2026-10-08 起只是历史批次记录，不再收待办）。
- **抽道具不看权重**（2026-10-10 道具重构）：小卖部铺货、机会卡道具卡、失物招领一律**在可获取池里
  等概率抽**，档位限定（黑市只出紫 / 金、科技与畸变按写死档发放）是**定位**而非概率。稀有度只由
  **价格**拦（`ItemData.QUALITY_PRICES` + 刷新曲线 + 黑市地皮价）。
