## 1. 对局仪表盘（回合 / 行动者 / 阶段流程）

### 动机
现在**「这是第几轮 / 轮到谁 / 卡在哪个阶段 / 还剩多久」散落在多处**（回合计数、桌面立牌、
`s_op_timer` 的倒计时条……），新手很难一眼读懂全局。做一个**仪表盘**把这些收拢成一条流程带，
核心回答三件事：**第几轮 · 轮到谁 · 到什么阶段**。

### 原型（用户已确认方向满意）
**`doc/game-design/对局仪表盘-原型.html`** —— 可交互（自动播放 / 逐阶段 / 换人 / 回合 +1）。
改视觉细节前先看它，别凭空重画。底部那排「控制按钮」只是原型演示用，**实现里不要**。

### 形态
- **顶部横条 + 右侧纵览**，浮在棋盘之上（半透明面板，沿用 `UIKit.PANEL_GLASS` + 金色强调 `ACCENT`）。
- **① 回合卡**：`回合 / ROUND N / 30` + 一条金色进度条。
- **② 当前行动 + 阶段 stepper**：色点 + 玩家名 + `tag`（轮到你 / 等待他行动 / 休眠 / 托管）；
  下面一行**阶段 stepper**：
  `回合开始 › ① 掷轮盘 › 移动 › 落地结算 › ② 使用道具 › 回合结束`
  —— 已过打勾（绿）/ 当前金色高亮 / 未来灰。
- **③ 等待提示**：显示「现在卡在哪个环节 + 剩余秒」（例：`小明 等待决定：买地/升级 · 剩 25s`）。
- **④ 玩家纵览（右侧竖排）**：每名玩家 = 色点 + 名字 + `现金 / 地皮数 / 体力`；
  轮到谁那一格金框高亮；休眠 / 托管带小标；出局置灰。

### 数据来源（**全部来自已同步状态，不需要新协议**）
| 元素 | 来源 |
|---|---|
| 回合 / 上限 | `s_state` 的 `round` / `max_rounds` |
| 当前行动者 | `s_state` 的 `turn`（peer）；轮内顺序 = 加入顺序 |
| 当前阶段 / 等待 | `s_state` 的 `await` / `await_peer`（`roll` / `prompt` / `card` / `shop` / `black` / `item`，见 `联机协议.md` §四） |
| 环节名 + 倒计时 | `s_op_timer(kind,left,total,owner_peer)`（环节名见 `game.gd` `OP_KIND_LABELS`） |
| 玩家状态 | `s_state` 的 `players[]`：`name/color/money/pos/alive/skip/sleep/stamina/items` |

> ⚠ `await` 与「阶段」**不是一一对应**：一个「落地结算」里还能先后出现 `prompt`（买/升级）、
> `card`（事件/抽卡）、`shop`、`black`。stepper 的「落地结算」是**粗粒度**，等待提示再显细粒度。

### 落点与施工要点
1. **脚本**：扩展 `scripts/table_hud.gd`（对局屏幕层，与左上角「暂停」/右上角「战报」同级），
   或新开 `scripts/dashboard.gd` 由它组装。数据全部读已同步的 `st` ⇒ **客户端（非房主）也准**。
2. **不要盖住棋盘的可点格**（参考 `开发台账.md` §二 #1 的面板遮挡约束）；横条贴顶、纵览贴右。
3. 阶段中文名与 `game.gd:47 OP_KIND_LABELS` 对齐（`roll=掷轮 / prompt=决定 / item=道具 / shop=小卖部 / black=黑市 / card=确认`）。
4. 悬停/点击纵览某玩家可复用现有「打开玩家面板」（`_open_player_popup`）。

### 待确认（施工前问作者）
- **位置/形态**：横条 vs 独立可开关侧栏 vs 极简迷你带；右侧「玩家纵览」是否保留（也可复用桌面立牌）。
- **阶段粒度**：「落地结算」是否再细分出 `决策 / 事件卡 / 小卖部 / 黑市 / 赌场`。
- **与现有倒计时条的关系**：仪表盘是否**取代**立牌/角条上的 `s_op_timer` 倒计时，还是并存。
- **状态机细化（作者后续会定）**：作者将给出一版更详细的对局阶段状态机；**stepper 的段划分以那版为准**，
  本条目先按上面 6 段落地，状态机定了再对齐。

### 验证
- 截图对照：`--shot=...table_plain.png` 核落位与不遮挡（3D / 2D 两端都看）。
- 联机：房主与客户端各截图，确认两端显示一致（判据是「都从 `st` 读」）。
- 阶段推进：跑一局，stepper 随 `await` 正确前进/打勾；倒计时与 `s_op_timer` 对齐。
