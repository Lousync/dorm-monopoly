# 小卖部

> 地图格型 `shop`，共 **6 家**（由机会 / 命运格腾位）。落在格上即进店。

## 一、进店与货架

- **落在地图小卖部格**即进店（不进则无事）。
- 每家店**独立 3 栏货架**，互不影响。
- 进店拉起**触发式全屏界面**（v0.5.0 批次 1 起，原先桌面上的常驻货架设施已撤下）：
  3 格货架卡面 + 价格 + 刷新 / 离开按钮，整屏独占，离开即回桌。
- 行动者 20 秒无操作 → 被请出（默认档，随房主「操作限时」挡位，见 `开局设置.md`）。
- **机器人（与休眠托管）进店也看得见**（批次 13 起）：机器人访客在动手买之前先**停 1.5 秒**，
  让「店开着 / 谁在里面」这份状态被人看见。**为什么需要**：真人访客会停在店里等操作，机器人却是
  一路同步买完就走 —— 不加这个节拍时，开 / 买 / 关全在**同一帧**里跑完，任何一端都来不及把界面
  显出来，机器人进店对**所有人不可见**（这是实机故障，不是观感微调）。代价：四人局里每次机器人
  进店多约 1.5 秒。
- **面板右上角 ✕ 可收起看棋盘**（#25，2026-10-05）：全屏压暗底会吞掉所有棋盘点击，原先只能靠
  「离开」才看得到棋盘。收起**不结束逛店**（会话与倒计时照旧），右下角留一枚
  「🛒 小卖部（购物中）· 点此继续」入口随时再展开；「离开」才是真正结束。
  收起是**本地 UI 态**（不广播）：别人看到的是同一份货架，收起与否各端独立。

## 二、铺货

- **品质权重**：白 40 / 绿 30 / 蓝 20 / 紫 5 / **橙 5**。
  - 橙池空时该份额并入紫。
  - 权重是**可变状态**，不是常量——已预告有道具 / 科技会改刷新概率。
- **售价**（占位，待数值专场）：白 600 / 绿 1000 / 蓝 1800 / 紫 3000 / 橙 4500。
  - **单件覆盖**：二青会酒寒暑 **¥8000**（`item_data` 的 `price` 字段，读 `ItemData.item_price`）。
- **货架卡面**：主动件且基础冷却 > 0 → 右上角显 **⏳ 冷却预览**（不压暗，区别于「冷却中」；§八）。


- **可获取池**排除：已被持有的唯一道具 + 小卖部在售 + 黑市在售 + 已焚毁的一次性道具。
- 已售栏位**保持空**；**刷新**或**再次进店**时整架重掷（见 §三）。
- **每次进店整架重掷**：掷 0 原地再次进店 / 买空后再来，看到的都是**新货架**（不再沿用上次那几件）。

## 三、操作

| 操作 | 规则 |
|---|---|
| 买 | **点界面里该栏的「买」按钮**（货架卡面旁，不可买时置灰）。扣现金、入包（背包 ≤ 5）；持**黑卡**且有剩余次数则免单；买后该栏清空 |
| 刷新 | 费用 = **500 + 300 × 全场刷新次数**；**全局递增、整局不重置**；**整架重掷**（三个货位全部换新，非只补空位） |
| 离开 | 结束本次逛店 |
| 收起 | 面板右上角 **✕**：收起界面去看棋盘，**不结束逛店**（会话与倒计时继续）；右下角「🛒 小卖部」入口再展开 |

> 交互分层（v0.5.0 批次 1 起）：货架改成**行动者独占**的全屏界面——只有行动者看得到并操作，
> 其他人只读到状态行的「XX 在小卖部购物…」；原「桌面公共货架 + 底部操作条」两条路已随设施撤下。

## 四、bot 策略

- 买得起的最贵一件（背包留位）→ 然后离开。
- **进店先停 1.5 秒**（批次 13 起，见 §一）：这个节拍只让「谁在店里」看得见，不改买什么。

## 五、设计待定

- 刷新价：起点 **500** / 步进 **300** 已定（见 §二），仅**是否封顶、是否整局不重置**随「数值专场」定稿。
- 品质权重各档份额回调；**运行时可变状态已就绪**（`game.gd` 的 `shop_weights`），待接线具体道具 / 科技。
- 各品质售价。
