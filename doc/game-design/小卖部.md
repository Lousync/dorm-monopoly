# 小卖部

> 地图格型 `shop`，共 **6 家**（v0.9.0 由 4 家增至 6 家）。落在格上即进店。

## 一、进店与货架

- **落在地图小卖部格**即进店（不进则无事）。
- 每家店**独立 3 栏货架**，互不影响。
- 进店拉起**触发式全屏界面**（v0.5.0 批次 1 起，原先桌面上的常驻货架设施已撤下）：
  3 格货架卡面 + 价格 + 刷新 / 离开按钮，整屏独占，离开即回桌。
- 行动者 20 秒无操作 → 被请出（默认档，随房主「操作限时」挡位，见 `开局设置.md`）。
- **机器人（与休眠托管）进店也看得见**（批次 13 起）：机器人访客在动手买之前先**停 1.5 秒**，
  让「店开着 / 谁在里面」这份状态被人看见。**为什么需要**：真人访客会停在店里等操作，机器人却是
  一路同步买完就走 —— 不加这个节拍时，开 / 买 / 关全在**同一帧**里跑完，任何一端都来不及把界面
  显出来，机器人进店对**所有人不可见**（这是实机故障，不是观感微调）。代价：四人局里每次机器人
  进店多约 1.5 秒。
- **面板右上角 ✕ 可收起看棋盘**（#25，2026-10-05）：全屏压暗底会吞掉所有棋盘点击，原先只能靠
  「离开」才看得到棋盘。收起**不结束逛店**（会话与倒计时照旧），右下角留一枚
  「🛒 小卖部（购物中）· 点此继续」入口随时再展开；「离开」才是真正结束。
  收起是**本地 UI 态**（不广播）：别人看到的是同一份货架，收起与否各端独立。

## 二、铺货

- **全池等概率**（2026-10-10 道具重构）：从**可获取池**里等概率抽一件。人为品质权重整套退场，
  **件数占比就是出现率** —— 白 27 / 蓝 20 / 紫 16 / 金 5，逐档占比见 `道具图鉴.md`「数量统计」。
  - 拦稀有度的只剩**价格**（`ItemData.QUALITY_PRICES`）：白 600 / 蓝 1600 / 紫 3200 / **金 8000**
    （= 默认开局现金 ¥20000 的四成，「买得起要下决心」）。
  - **单件覆盖**：二青会酒寒暑 **¥2600**（`item_data` 的 `price` 字段，读 `ItemData.item_price`；
    2026-10-10 由 ¥8000 下调 —— 它是兑换券，产出只是一件蓝档强化件）。
- **同店三栏去重**：一家店的三个货位互不重复（抽第 N 栏时排除本店已在售的那几件）—— 去重范围
  **只限本店**，各店货架彼此独立。重掷会**先清空整架再去重**，免得拿上一架的旧值排掉本可上架的件。
- **货架卡面**：主动件且基础冷却 > 0 → 右上角显 **⏳ 冷却预览**（不压暗，区别于「冷却中」；
  规格见 `道具系统.md`「卡片规格」）。

- **可获取池**排除：已被持有的唯一道具 + 小卖部在售 + 黑市在售 + 已焚毁的一次性道具。
- 已售栏位**保持空**；**刷新**或**再次进店**时整架重掷（见 §三）。
- **每次进店整架重掷**：掷 0 原地再次进店 / 买空后再来，看到的都是**新货架**（不再沿用上次那几件）。

## 三、操作

| 操作 | 规则 |
|---|---|
| 买 | **点界面里该栏的「买」按钮**（货架卡面旁，不可买时置灰）。扣现金、入包（背包 ≤ 5）；持**黑卡**且有剩余次数则免单；买后该栏清空 |
| 刷新 | 费用 = **800 + 400 × 全场刷新次数**（`ItemData.REFRESH_BASE` / `REFRESH_STEP`）；**全局递增、整局不重置**；**整架重掷**（三个货位全部换新，非只补空位） |
| 离开 | 结束本次逛店 |
| 收起 | 面板右上角 **✕**：收起界面去看棋盘，**不结束逛店**（会话与倒计时继续）；右下角「🛒 小卖部」入口再展开 |

> 交互分层（v0.5.0 批次 1 起）：货架改成**行动者独占**的全屏界面——只有行动者看得到并操作，
> 其他人只读到状态行的「XX 在小卖部购物…」；原「桌面公共货架 + 底部操作条」两条路已随设施撤下。

## 四、bot 策略

- 买得起的最贵一件（背包留位）→ 然后离开。**贵贱按 `ItemData.item_price`（含单件 `price` 覆盖）
  判定，不是按档价** —— 只读档价会把二青会酒寒暑看成紫档价，挑中它再被真实价拒付、空手离店。
- **进店先停 1.5 秒**（批次 13 起，见 §一）：这个节拍只让「谁在店里」看得见，不改买什么。

## 五、设计待定

- 刷新价：起点 **800** / 步进 **400** 已定（见 §三），仅**是否封顶、是否整局不重置**随「数值专场」定稿。
- 各档售价是否再调（现为白 600 / 蓝 1600 / 紫 3200 / 金 8000）。
- 数量限购（如将来需要）。
