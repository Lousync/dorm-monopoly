# 小卖部

> 地图格型 `shop`，共 **4 家**（由机会 / 命运格腾位）。落在格上即进店。

## 一、进店与货架

- **落在地图小卖部格**即进店（不进则无事）。
- 每家店**独立 3 栏货架**，互不影响。
- 桌面上的小卖部**设施**公开显示货架卡面 + 价格（全桌可见）；**操作条只给行动者**（屏幕底部居中）。
- 行动者 20 秒无操作 → 被请出（默认档，随房主「操作限时」挡位，见 `开局设置.md`）。

## 二、铺货

- **品质权重**：白 40 / 绿 30 / 蓝 20 / 紫 5 / **橙 5**。
  - 橙池空时该份额并入紫。
  - 权重是**可变状态**，不是常量——已预告有道具 / 科技会改刷新概率。
- **售价**（占位，待数值专场）：白 600 / 绿 1000 / 蓝 1800 / 紫 3000 / 橙 4500。
- **可获取池**排除：已被持有的唯一道具 + 小卖部在售 + 黑市在售 + 已焚毁的一次性道具。
- 已售栏位**保持空**，直到有人刷新或有新铺货。

## 三、操作

| 操作 | 规则 |
|---|---|
| 买 | **点桌面货架上的卡**（营业时卡片可点、显示「点击购买」），或点底部操作条的「买」按钮。扣现金、入包（背包 ≤ 5）；持**黑卡**且有剩余次数则免单；买后该栏清空 |
| 刷新 | 费用 = **500 + 300 × 全场刷新次数**；**全局递增、整局不重置** |
| 离开 | 结束本次逛店 |

> 交互分层：桌面货架是**公共信息**，营业时**行动者**点它即可买（其他人点了无效）；
> 底部操作条为备用入口。

## 四、bot 策略

- 买得起的最贵一件（背包留位）→ 然后离开。

## 五、设计待定

- 刷新价曲线的起点 / 步进 / 封顶 / 是否重置，随「数值专场」定稿。
- 品质权重份额回调；落实「可变状态」以支持未来的道具 / 科技修改刷新概率。
- 各品质售价。
- 数量限购（如将来需要）。
