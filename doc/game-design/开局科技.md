# 开局科技（开局三选一）

> 房主开启「科技」后，发车前每人独立三选一，是本局的一次性强化。
> 与道具的交集见 `道具系统.md`，开关与默认值见 `开局设置.md`。

## 一、机制

- **发车前**，每名玩家**独立发现三张科技、选一张**。
- **结果公告全员**（公开，定稿）。
- 科技池为数据表，可扩展。
- **科技效果一律无 buff/debuff 标签**——香皂对科技无效（持皂党照样吃白手起家的清资金、强身健体的休眠）。

## 二、科技图鉴

### 白手起家

- **效果**：起始资金清零（跟随开局设置）→ 发现三张**紫道具**选一张 →
  该道具**冷却值 +1（上限 5）**，并获**自动补充**：每次冷却结束的回合开始时，道具自动回格。
- **牵出的子系统**：道具自动补充。

### 强身健体

- **效果**：本局**道具体力支付一律 −1（下限 1）** → 累计每用 3 次道具，**下一回合休眠**，计数清零。
- **定稿**：**冷却不随支付减少**（冷却固定 = 道具基础消耗）。
- **牵出的子系统**：道具使用计数 → 休眠钩子（复用休眠状态机）。
