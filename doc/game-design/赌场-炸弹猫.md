# 赌场 · 炸弹猫

> 地图格型「宿舍赌场」（2 格）。落到格上全员下注，玩一局炸弹猫。

## 一、触发与注码

- 落到「宿舍赌场」格 → **全员下注**（注码 **800**，按各自现金封顶）→ 奖池 = 所付之和，**赢家通吃**。
- 存活 < 2 人时不开局，直接离开。

## 二、炸弹猫流程

- 牌堆共 12 张：**炸弹 ×3 / 拆除 ×2 / 小鱼 ×7**（洗牌）。
- 轮流出牌，每次选**抽牌堆顶**或**牌堆底**：

| 抽到 | 结果 |
|---|---|
| 炸弹 | 手上有「拆除」则消耗一张化解，否则**出局** |
| 拆除 | 收入手中，可抵消一次炸弹 |
| 小鱼 | 无效果 |

- **最后存活者**通吃奖池。
- 单人思考超时默认抽顶（托管）。

## 三、透视（私密信息）

- 每人限一次「偷看牌堆顶」；走**私密通道**，只有该玩家能看到——
  符合「私人信息永远走屏幕私弹」的红线（见 `设计决策留痕.md`）。

## 四、表现分层

- **桌面设施**：绿呢牌桌 + 金色滚边 + 卡背装饰，常驻显示奖池与状态行（公共信息）。
- **玩法弹层**：当前是全屏弹层进行交互，迁到桌面面板的时机待拍板。
