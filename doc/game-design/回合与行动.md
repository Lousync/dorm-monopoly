# 回合与行动

> 对局主循环：回合顺序、一回合两阶段、休眠与托管的区别。
> 协议与同步细节见 `development/联机协议.md`。

## 一、回合顺序

- 玩家按加入顺序**轮流行动**；破产 / 出局者被跳过。
- 所有人各行动一次为**一回合（round）**。
- 第 **30 轮**结束，按身家结算（见 `经济与胜负.md`）。

## 二、一回合两阶段

```
回合开始结算 → ① 转轮盘 → 移动 → 落地结算 → ② 使用道具 → 回合结束
```

### 回合开始

- 体力 +1（上限 5）；道具冷却 −1。
- 香皂融化计数 −1，归零自动丢弃回池。
- **每回合进账**（两条各自独立生效）：绿货「信托基金」**+¥200**（见 `道具图鉴.md`）；
  黄金科技「零花钱规划」**+¥100**（见 `开局科技.md`）。
- 重置「本回合已用道具」标记。
- 休眠（小黑屋）玩家：以上被动 / 自动结算**照常**，但本回合强制保守托管。

### ① 转轮盘

幸运转轮 0~12：

| 点数 | 结果 |
|---|---|
| 1~11 | 前进对应步数 |
| **12** | 满值，走完后再**额外行动一次** |
| **0** | 原地待命一回合（仍算完成投掷，之后可用道具） |
| 连续 3 次 ≥10 | 兴奋过度，被查寝送宿委会（跳过一回合） |

- 作弊器 / 强制点数类道具可指定本次点数（按正常规则结算）。
- 真人超时由系统代掷（默认 35 秒，随房主「操作限时」挡位，见 `开局设置.md`）。

### 操作倒计时条（全员可见）

- 每个操作窗口（掷轮 / 决定弹窗 / 道具 / 小卖部 / 黑市）开启时，**当前行动者那一条**出现一行
  倒计时（环节名 + 进度条 + 剩余秒数），所有人都能看到他还剩多久；窗口换人时倒计时跟到下一位。
  **载体史**：座位卡（批次一~四）→ 桌上立牌（批次 5）→ 四角身家条（批次 9 立牌退场后成为唯一落点）
  → 身家条 + 顶部名册条（批次 12 D）→ 名册条（批次 13 ② 搬到左上角
  「暂停」旁、一行瘦身成一格）→ **桌面立牌（v0.10.0：名册条整体删除，他人那一份搬到桌面上每名对手一块立牌）**。「我」那一条仍在左下角。
- 剩余 ≤5 秒进度条与秒数变红；「不限时」挡显示「不限时」、无进度条。
- 秒数随挡位（15/30/60/现状/不限时）走；挡位中途修改时窗口重计时、条子重启。
- 实现与同步口径见 `development/联机协议.md`（`s_op_timer`）；位置取舍见
  `设计决策留痕.md` §四、§十三。

### 移动与落地结算

- 逐格移动动画；途中**踏过起点领工资 ¥4500**。
- 按落点格型结算：买地 / 升级 / 收租（`棋盘与地产.md`）、事件卡（`事件卡.md`）、
  失物招领（捡道具）、特浓咖啡（再行动一次）、小卖部（`小卖部.md`）、赌场（`赌场.md`）、送监。
- 买地 / 升级是**弹窗询问**，默认 25 秒未答视为拒绝（随房主挡位）。

### ② 使用道具

- **每回合限用 1 次**（被动不计入）；有可用道具才进入该阶段。
- 使用窗口 = 转轮结算完成 → 本回合结束（含商店 / 黑市 / 赌场期间）。
- 不占用、不跳过掷轮；超时（默认 12 秒，随房主挡位）自动跳过。
- 闸门三道：体力足够、该道具冷却为 0、本回合未用过。
- 休眠玩家跳过该阶段。

机制细节见 `道具系统.md`。

## 三、休眠 vs 跳过回合（易混）

| | 跳过回合（skip） | 休眠（sleep，小黑屋） |
|---|---|---|
| 被动 / 自动结算 | ❌ 不享受 | ✅ 照常 |
| 掷轮 | 整回合不掷 | 系统代掷 |
| 买地 / 升级 | — | 一律拒绝 |
| 商店 / 赌场 | — | 自动离开 / 自动抽牌 |
| 道具阶段 | — | 跳过 |
| 触发 | 宿委会反省（含连续 3 次 ≥10 被查寝送入） | 黑市挨打 |

## 四、决策与托管

- 买地 / 升级这类决策向目标玩家**弹窗询问**；真人弹窗、机器人按策略、休眠者拒绝。
- 超时 / 掉线 → 系统托管（代掷、代决定、商店 / 黑市自动处理）；详见 `development/联机协议.md`。
