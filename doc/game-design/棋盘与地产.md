## 二、地产

- **10 组、每组 3 块**，沿路径由便宜到贵。每组备了 6 个名字，当前只取前 3。

| 组键 | 组名 | 地价 | 基础租金 |
|---|---|---|---|
| daily | 便利店 | 1600 | 500 |
| service | 生活服务 | 1900 | 600 |
| canteen | 餐饮 | 2200 | 700 |
| study | 学习 | 2600 | 800 |
| sport | 运动 | 3000 | 900 |
| teach | 教学 | 3400 | 1000 |
| dorm | 宿舍楼 | 3800 | 1150 |
| fun | 娱乐 | 4200 | 1300 |
| night | 夜宵 | 4700 | 1400 |
| health | 健康 | 5200 | 1600 |

### 规则

- **购买**：落到无主地块、现金够 → 弹窗询问；买入价 = 地价。
- **升级（装修）**：落到自己的地块 → 询问升级；费用 = **地价 × 50%** / 级，上限 **3 级**。
- **收租**：落到他人地块 → 租金 = **基础租金 × (1 + 等级) ×（垄断该组则 ×2）**。
- **垄断**：集齐同组 3 块 → 该组租金翻倍；被拆散则取消。
- **破产**：付不起时玩家出局，现金清零、名下地产收归无主、等级清零（见 `经济与胜负.md`）。

### 焦土

- 触发：`亡牌飞行员 coco` 炸地（见 `道具图鉴.md`）。
- 性质：**无归属、不产租、不算垄断**、等级清零；任何玩家落地自动扣**捐款**、累进进度。
- 捐款：当前占位 **400**（香皂拦截则进度不涨）。
- 恢复：进度 ≥ 地价后，恢复为**无主**地产、等级 Lv0、进度清零。
- 多块焦土**各自独立**计时。
- 表现：格子换废墟配色 + 「焦土 x/y」进度文本（hover / 恢复会还原）。
