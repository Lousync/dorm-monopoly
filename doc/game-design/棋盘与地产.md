# 棋盘与地产

> 数据源头：`scripts/game_data.gd`（几何与数值），坐标换算与租金为**静态纯函数**，渲染与单测共用。
> 更新：2026-10-02。

## 一、棋盘

- **56 格环形**：由 18×12 外圈生成（`BOARD_COLS=18`、`BOARD_ROWS=12`），总格数 `cols*2+rows*2-4 = 56`。
- **四角**（`corner_indices()`）：
  | 路径序号 | 坐标 | 类型 | 名称 |
  |---|---|---|---|
  | 0 | 右下 | `start` | 起点（踏过领工资） |
  | 17 | 左下 | `jail` | 宿委会（反省） |
  | 28 | 左上 | `rest` | 卧谈会（免费休息） |
  | 45 | 右上 | `go_jail` | 查寝！（直接送宿委会） |
- **几何**：`grid_of(i)` 路径序号→格坐标，`index_at_grid(col,row)` 反查；均为纯函数，单测覆盖闭合性。
- **视觉**：格子世界尺寸 112×112（`board_view.TILE=112`），已为未来「上桌 / 2.5D」预放大版面（见 `设计决策留痕.md`）。
- **镜头**：自研 2D 相机（注视点/缩放/旋转）在 `board_view.gd`；点座位卡 / Tab / 空格切视角。

### 规则

- **购买**：落到无主地块，现金够 → 弹窗询问（`_ask("buy")`）；买入价 = 地价。
- **升级（装修）**：落到自己的地块 → 询问升级；费用 = `地价 × 50%`/级，上限 `MAX_LEVEL=3`。
- **收租**：落到他人地块 → 租金 = `基础租金 × (1+等级) × (垄断该组则 ×2)`（`rent_for`）。
- **垄断**：集齐同组 3 块 → 该组租金翻倍；被拆散则取消。
- **破产**：`_pay` 付不起时玩家出局、现金清零、名下地产收归无主（`owner=NO_OWNER`、`level=0`）。
  > ⚠ 已知缺口：设计 §10 要求破产者**清空道具并回唯一池**，当前 `_pay` 只处理钱与地产，未清道具。

### 焦土（coco / 黑市子系统）

- 触发：`亡牌飞行员coco` 炸地（见 `道具图鉴.md`）。
- 状态：`tile.soil = true`、`owner=NO_OWNER`、`level=0`、`soil_prog=0`。
- 性质：**无归属、不产租、不算垄断**；任何玩家落地自动扣捐款累进 `soil_prog`。
- 捐款：`SOIL_DONATE`（当前占位 400，香皂拦截则进度不涨）。
- 恢复：进度 ≥ 地价后恢复为**无主**地产、等级 Lv0、进度清零；多块焦土各自独立计时。
- 表现：格子换废墟配色 + `焦土 x/y` 进度文本（hover / 恢复会还原）。
