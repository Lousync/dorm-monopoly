# 赌场

> 地图格型 `casino`（2 格）。逻辑在 `scripts/casino.gd`（game 的子节点），表现与相机在 `board_view.gd`，纯规则在数据/工具层。
> **原「炸弹猫」玩法已移除**（见 §五）。当前游戏为「投骰子」。
> 更新：2026-10-02 · v0.2.1。

---

## 一、触发与注码

- **落到「宿舍赌场」格** → **全员下注**（`GameData.CASINO_STAKE`，按各自现金封顶）→ **奖池 = 所付之和**（赢家通吃）。
- 存活 **< 2 人**时不开局，直接离开。
- 每人下注额 = `CASINO_STAKE`（当前 800，数值待专场）。

## 二、演出（相机聚焦）

进入赌场是一段**演出**，分三步：

1. **相机聚焦**：所有玩家（各自）的棋盘相机**移到赌场区域**，并**缩放到赌场区边缘正好铺满屏幕**。
2. **相机仍可操作**：到位后相机**不是定死的**——玩家仍可**拖拽平移**与**滚轮缩放**（复用对局相机；此时段内对局层不抢镜头）。
3. **抽游戏** + **场景布置**（见 §三）。

## 三、流程

```
落到赌场格 → 全员下注 → 相机聚焦赌场 → 抽取本局游戏（CSGO 开箱式卷轴）
           → 赌场区域变为该游戏场景 → 玩完 → 赢家通吃/平分 → 结算 → 相机回总览
```

### 抽游戏

- 赌场中央一条**横向卷轴**滚动（先快后慢、轻微回弹），中线标记命中本局游戏（CSGO 开箱手感）。
- 命中后卷轴淡出，赌场区域**切换为该游戏的场景布置**。
- **当前抽奖池只有「投骰子」是真实游戏，其余为占位**（因此**固定抽到「投骰子」**）；以后抽奖池扩充（见 §六）。

### 游戏：投骰子

- **每名存活玩家同时掷一颗 6 面骰**（掷骰动画后一并定格）。
- **点数最大者通吃奖池**。
- **平局**：点数并列最大者**平分**奖池（`奖池 / 并列人数` 向下取整，余数按行动顺序逐人 +1）。

## 四、表现

- **桌面设施**：赌场常驻显示**奖池**与**状态行**（`board.update_casino(pool, status)`）。
- **赌场区域场景**：抽游戏卷轴 / 骰子在该区域的世界坐标内渲染；相机聚焦后即"赌场区域变成游戏场景"。
- **屏幕层**：仅状态提示；私人信息无（本游戏无透视）。

## 五、已移除：炸弹猫

- 原「炸弹猫」（12 张牌堆：炸弹×3 / 拆除×2 / 小鱼×7，轮抽、拆除化解、小鱼比多）**整块删除**：含纯规则 `scripts/bombcat.gd`、赌桌 UI 与 `tests/casino_test.gd` 中的对应规则测试。
- 删除原因：功能有问题，且改用更简单直观的「投骰子」。

## 六、同步（联机）

全程 **host 权威**：下注、掷骰、判定在房主侧；客户端只渲染。

| RPC | 方向 | 载荷 | 用途 |
|---|---|---|---|
| `s_casino_start` | 房主→全员 | 游戏名、注码、奖池、参与顺序 | 触发**相机聚焦 + 抽游戏**演出 |
| `s_casino_draw` | 房主→全员 | 命中游戏名 | 卷轴定格、切换场景（可选，或并入 start） |
| `s_casino_roll` | 房主→全员 | 各 peer 点数 | 骰子定格 |
| `s_casino_end` | 房主→全员 | 赢家数组、奖池 | 结算、相机回总览 |
