# 黑市

> **仅由机会卡进入，不占地图格**。进店强制，且不算 debuff（香皂拦不住）。

## 一、进入

- 通道：机会卡事件「进入黑市」（见 `事件卡.md`）。
- 开局设置可关闭；关闭时构建卡池即过滤该事件，整局不出现。

## 二、货架与计价

- **3 栏货架**，品质权重：紫 70 / 橙 30（紫 / 橙起步）。
- **一切消费用地产**（价目定稿）：

| 项目 | 地皮价 |
|---|---|
| 紫货 | 1 块 |
| 橙货 | 2 块 |
| 刷新 | 1 块（**固定不涨价**） |
| 出口费 | 1 块 |

- 交地**由玩家自选**（逐块点选自有地皮）；bot 交最便宜。
- 被收地皮**回归无主、可被再次购买**，且**等级清零**。
- 唯一性：黑市在售的唯一道具同样占用唯一池（不同货架不会重复上架）。
- **刷新不涨价**——递增刷新价只属于小卖部。

## 三、挨打（付不起）

- 付不起地皮（**含带着 0 块地皮进店**，以及出口时刻凑不齐）：
  扣**当前现金一半（向下取整）** + **小黑屋（休眠一回合）**，被扔出店。
- 例：带 1 块地皮买完东西 → 出口费凑不出 → 挨打。

## 四、小黑屋 = 休眠

- 语义是**休眠**（区别于「跳过回合」，对照表见 `回合与行动.md`）：
  - 自己回合**被动 / 自动结算照常**（体力 +1、冷却 −1、香皂融化、信托基金发放）；
  - 系统**代掷**；**买地 / 升级一律拒绝**；**商店自动离开**；**赌场自动抽牌**；**道具阶段跳过**。
- 20 秒无操作 → 托管自动先付完当前动作、再用最便宜地皮付出口费（凑不齐则挨打）
  （20 秒为默认档，随房主「操作限时」挡位，见 `开局设置.md`）。

## 五、bot 策略

- 留 1 块地皮付出口费，用余下地皮买**最值的一件**（橙 > 紫）→ 交出口费走人。
