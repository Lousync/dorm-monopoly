# 经济与胜负

> 资金收支、转轮与反省、破产出局、胜负判定。数值表在 `scripts/game_data.gd`。

## 一、资金

| 项 | 值 | 说明 |
|---|---|---|
| 起始资金 | 20000 | 每局开局 |
| 工资 | 4500 | 踏过 / 停在起点领取 |

> **「强制缴费」与「兼职 / 奖励」两类格已于 0.5.0 退役**（本表原写着 4 + 6 个格、
> 400 ~ 1500 / 400 ~ 2000），腾出的位置改铺失物招领（捡道具）与特浓咖啡（再行动一次）——
> 两者都不直接给钱，故不在本表。现金收支现在来自：工资、地产买卖与收租、事件卡、赌场奖池，
> 以及带 debuff 标签的罚项。

- 罚金 / 扣钱 / 后退 / 送监 / 请客等**带 debuff 标签**，持「空想者的香皂」可免疫（逐受害者独立）。
- 租金支付、购买、赌注、道具消耗为**中性**，永不免疫。

## 二、转轮与反省

- 幸运转轮 0~12（细则见 `回合与行动.md`）：12 满值额外再走一回合；0 原地待命一回合；
  连续 3 次 ≥10 兴奋过度，被查寝送宿委会（跳过一回合）。
- 宿委会（左下角格）：整回合被压制、**被动也不享受**——「跳过回合」语义。
- 「小黑屋」是另一种惩罚，语义是**休眠**（被动照常、保守托管），见 `黑市.md`。

## 三、破产与变卖

- **出局判定保留**（2026-10-04 确认）：破产者出局——现金清零、名下地产收归无主且等级清零、
  **道具清空（唯一道具回池）**；进入观战，不可再用道具。
- **变卖保底（2026-10-04 定稿；2026-10-06 实装）**：**支付不足**时先进入变卖：玩家**限时自选**名下地皮
  逐块变卖，每块按「该地皮价值（含房屋 = 地价 + 等级 × 升级费）× **50%**」回收现金；
  **凑足应付款即停、余款保留**。名下无可变卖资产（或凑不足）→ 按原破产流程出局。
  （比例 2026-10-09 由 30% 改 50%，用户拍板；常量单一来源 = `GameData.LIQ_RATE`。）
  付得起、付完恰好归零**不算破产**，不触发变卖。变卖后的地皮无主、等级清零、可被再购买。
  - **那个「限时」是哪一档**（2026-10-09 补）：= 开局设置「**操作限时**」里的**「决定」档**
    （`game.gd` 的 `_run_liquidation()` 走 `_await_turn_window("prompt", …)`），
    与买地 / 装修 / 抽卡确认**同一个窗口**，**没有单独的旋钮**。
    现状档 = **25 秒**（`GameData.PROMPT_TIMEOUT`）；15 / 30 / 60 秒档即该秒数；
    **「不限时」档不自动兜底** —— 挂机会真的停住整局（该档的定义，非缺陷）。详见
    `开局设置.md` §三之一。
- **托管 / 机器人 / 超时**：无法自选时自动变卖，顺序按累计投入**从低到高**（实装口径；比例与顺序仍待数值专场复核）。
- **开关**：变卖保底开局由房主设置，默认开（见 `开局设置.md` §二）。
- **待定**：自动变卖顺序（暂定投入从低到高）；回收比例 50% 仍待数值专场复核。

## 四、胜负

- **最后存活**：只剩 1 人 → 该玩家胜；全员破产则学校胜。
- **回合上限**：到上限轮结束，按**总资产**排名结算（结算口径含钻石科技「金字招牌」的地皮 ×1.3）——
  身家 = 现金 + Σ(地价 + 等级 × 升级费用)，最富有者胜。档位见 `开局设置.md` §三
  （2026-10-09 起 30 / 45 / 60 / 80 / 不限，默认 30）。
  回合上限可设 **30 / 60 / 90 / 不限**（2026-10-04 拍板改档位制，默认 30；
  「不限」只能靠胜利条件或全员破产结束）。
- **目标现金（2026-10-04 拍板，房主可设）**：先到达设定现金金额者**立即获胜**；金额由房主开局
  自行设置，**默认 ¥50000**（可设范围随数值专场定）。与回合上限并存：先到先赢，
  到轮未达标则按身家结算。
- 结束时停表，各端展示排名 + 彩带。
