# 道具系统

> 道具的通用机制：体力、冷却、使用窗口、唯一性、背包，以及金货各自牵出的子系统。
> 逐件道具档案见 `道具图鉴.md`；科技见 `科技.md`，畸变见 `畸变.md`，
> 黑市见 `黑市.md`，小卖部见 `小卖部.md`；全局术语见 `术语表.md`。

## 一、体力（闪电）

- 每人独立：**初始 3、上限 5**，自己回合开始时 +1。
- 使用主动道具要求「当前体力 ≥ 道具消耗」；用后立即扣减。

## 二、冷却

- 冷却是**逐件独立数值**（`item_data` 的 `cooldown` 字段），与体力消耗**解耦**（2026-10-04 数值专场拍板）：
  能量管爆发预算、冷却管复用节拍。**科技对冷却的修正已实装**（2026-10-07）：黄金「手速惊人」冷却 −1
  （下限 1）、钻石「熟能生巧」用后不进冷却，见 `科技.md`。
- 回合开始时判定：冷却 > 0 则该道具本回合不可用，并 −1。
- 冷却与体力是两条独立的闸；再加上「每回合限用一次」，共三道。

## 三、使用窗口

- 只能在**转轮点数结算完成 → 本回合结束**的区间内使用（含移动、落地结算，
  以及商店 / 黑市 / 赌场界面期间）——先掷轮，后用道具。
- **每回合限用 1 次**（被动道具不计入）；**奖励件除外**——如「组队学习·寒暑」走**独立次数**
  （每回合独立 1 次、不占普通上限、不占「双开 / 重修卡」那套上限，见 §八）。
- 转轮 0 的「原地待命」回合也算完成投掷，仍可用道具。
- 用道具不占用、也不跳过掷轮。
- 选玩家类道具：**按住手牌拖动**，从那张卡拉出一条**屏幕层瞄准箭头**指向鼠标；拖到**桌上对手那块立牌**上松手即选定（也可直接点那块牌；Esc / 右键取消）。
  （落点史：桌上立牌（批次 5）→ 屏幕四角条（批次 9）→ 名册条（批次 12 D / 13 ②）→ **桌面立牌（v0.10.0）** —— 名册条已随 3D 房间第四次改版整体删除。）
- 选地块类道具：同样**拖动 + 箭头**，拖到棋盘上高亮的一格松手（也可点它）。
- **两段式**（强拆令 / 抄家队）：先拖到玩家松手，箭头改指**他名下高亮的地皮**，再拖 / 点一块。

## 四、被动道具

- 不耗体力、不进冷却、不占每回合次数，**持有即生效**。
- 可**主动丢弃**（道具栏丢弃按钮 + 二次确认）；丢弃后回道具池。

## 五、唯一性

- **判据 = 「多件会破坏某件事」，不按品质档**（2026-10-10 拍板）。全仓只有 **4 件** `unique: true`
  （逐件理由写在 `道具图鉴.md` 各自条目里）：
  - **倍率型**租金增益 —— `招财猫`（每块地 +400）/ `保安巡逻`（×1.3）：多件会**加速雪球**；
  - **全局**负面免疫 —— `空想者的香皂`：多件会**稀释整套 debuff 体系**（它自带 10 回合限时）；
  - **地皮护罩** —— `园中叶`：多件会让**抄家 / 强拆 / 征收整套攻击玩法失效**。
  **金档不再一律唯一**（改前 5 件金货全唯一）。
- **两条既有先例**（证明这不是新发明）：
  - 租金类**常驻**增益全仓只有 `招财猫` / `保安巡逻` 两件，**两件本来就都是唯一** ⇒ 保留与既有意图一致；
  - 防御类里 `护腕`（蓝·一次性·抵消后损坏）**本来就不是唯一** ⇒ 「**一次性防御不唯一**」已有先例。
- **放开的那 17 件为什么可以放开**：一次性或自带「每局一次」的（`应急基金` / `护身符` / `蛋蛋节` /
  `亡牌飞行员coco`）· 消耗品 / 主动（`黑卡` / `二两寒暑`）· 纯效用与容量（`置物架` / `充电宝` /
  `错峰用电` / `重修卡`）· **定额型**收益（`信托基金` / `校园卡` / `校历` / `幸运数7` / `砍价高手`）·
  单项防御 / 位移（`雨伞` / `公交卡`）—— 多件并存都不破坏任何机制。
- **放开要解决的**：改前 21 件唯一 × 68 件小池 × 4 人 ⇒ 中后期可获取池明显收窄；**金档 5 件全唯一**
  更让**金池整个空掉**，而**黑市的候选池只有「紫 + 金」** ⇒ 黑市退化成「只出紫」。
- **判定**只看道具自己的 `unique` 字段（唯一来源 `scripts/item_data.gd`）：铺货 / 礼物 / 发现时，
  已被持有的唯一道具从可获取池排除。定义见 `术语表.md`。
- **货架在售的同样占用唯一性**——不同货架不会同时出现两件（2026-10-01 补定）。
- 丢弃、或持有者破产清栏 → **回道具池**，之后可再次上架。
- **一次性道具（`type=consumable`）用后焚毁**：不回池、永久消失（蛋蛋节 / 亡牌飞行员coco /
  **二青会酒寒暑**）；未使用就丢弃的仍回池。
- **冷却型主动件（如二两寒暑）**：用后**进入冷却、留在持有者背包**，**不流回道具池**
  （与「一次性用后焚毁」相对；2026-10-05 定稿）。

## 六、背包

- 每人 **5 格**；满格不可购买，也不可收取新道具。

## 七、效果标签

每个会施加给玩家的效果都在数据里**人工标注**三档，运行时按标签判断——
利弊随局面变化，故不做自动判断，标注权在设计者。

| 标签 | 效果 |
|---|---|
| **debuff** | 机会卡扣钱、后退、送监；黑市出口费；黑市挨打（半款 + 休眠）；畸变不利项；平均主义；亡牌炸地；焦土捐款 |
| **无标签** | **科技的全部效果**（如「精力充沛」加体力上限、「信托基金」每回合进账），香皂一律挡不住 |
| **中性** | 租金支付、购买、赌场下注、道具消耗——永不免疫，否则正常经济会被打穿 |

## 八、金货子系统

> **设计纲领**：金货（顶档）模仿炉石橙卡——每件都有独特机制与强度，改写规则、引入新子系统；
> 低档只是对现有规则的强力调用（如平均主义）。新金货入表时主动排查与已有金货的联动与冲突，
> 摆给设计者知情确认。框架预留**自定义效果插槽**，不走原语拼装。

| 金货 | 牵出的子系统 |
|---|---|
| 黑卡 | 购买次数计费器 |
| 空想者的香皂 | 效果标签系统 + 融化状态机（分段表现由剩余回合驱动，正式贴图待美术） |
| 蛋蛋节 | 礼物分发系统 + 一次性焚毁 |
| 亡牌飞行员 coco | **焦土地块状态机**：原地产定义完整保存；无归属（不产租）；任何玩家落地自动扣**捐款**累进进度；达标后恢复原功能并**变为无主**；多块焦土各自独立计时 |
| 园中叶 | **地产护罩**：名下的地皮不会被 `抄家队` 降级、被 `强拆令` 拆成无主、被 `宿舍改造`（学校）征收 —— **只挡这三处点名机制**，不为「地皮易主」整体兜底（机会卡的夺地 / 强买、coco 的炸地都不在其中，见 `道具图鉴.md` 该条）。地产层标记，与香皂 / 护腕的 debuff 免疫并列而非嵌套 |

> **紫档里的例外**：`二青会酒寒暑`（2026-10-10 四档重构由「橙」落 **紫**）仍牵出两个子系统，
> 是低档里唯一带独特机制的一件 —— **单件售价覆盖**（¥2600，同日由 ¥8000 下调）+
> **隐藏授予件**：授予强化版「组队学习·寒暑」（1⚡ / 无冷却 / 独立次数）。

**已知金货联动**（知情确认过）

- 香皂 + 黑市：出口费、挨打双双免疫，皂党进黑市零风险。
- 香皂 + 亡牌：施放者持皂 = 自己地皮无伤、只炸别人的。
- 香皂 vs 科技：科技效果无标签，皂党照样吃白手起家的清资金与强身健体的休眠。

## 九、卡片规格（美术对接）

卡面规格已二版确认（2026-09-30；原型图不在库内，比例与位置不作参考，只取元素关系）。

**元素与位置**：竖版卡片本体；左上角与右上角各一枚外挂圆徽章；上部大图区 = 道具图画；
图区下方横条 = **道具名称**；其下文本区 = 道具描述；底部居中横条 = 品质。
两枚徽章骑在卡边（半出卡外）。

| 元素 | 绑定数据 | 显示规则 |
|---|---|---|
| 左上徽章 | 体力消耗 **或** 被动标记 | 主动道具 = ⚡ + **生效值**（高于基础值显红、低于基础值显绿）；**被动道具 = 被动图标占同一位置** |
| 右上徽章 | **计数位 / 一次性标 / 冷却预览** | **一次性道具（`type=consumable`）= 「一次性」胶囊标**；**冷却中 = ⏳ + 剩余回合**（压暗）；**未使用且有基础冷却 = ⏳ + 生效冷却预览**（不压暗，颜色同上「高于基础显红、低于基础显绿」）；其余计数位（黑卡 = 剩余购买次数，香皂 = 剩余融化回合）= 数字 |
| 图画 | 每道具一张美术图 | `icon` 字段 → `assets/icons/item_*.png`（缺素材回退占位）；香皂在此区叠加融化表现（剩余回合 → 档位） |
| 名称条 | 道具名称 | 图区与描述之间 |
| 描述 | 道具描述文本 | 自动换行；一次性道具文案含「每局一次」 |
| 品质条 | 四档品质 | 显示名 **普通 / 稀有 / 史诗 / 传说**（对应内部色键白 / 蓝 / 紫 / 金）+ 品质色；同时决定卡框颜色 |

- **价格不上卡片**：现金价 / 地皮数只在小卖部与黑市的商店界面里随货架展示，卡片本体不含价格元素。
- **卡片状态**：普通 / 冷却中（右上显剩余、画面压暗）/ 被动（左上为被动标）/
  计数中（黑卡剩余次数、香皂剩余回合）/ 一次性 / 可选（发现三选一高亮）/
  买不起（商店面板将卡与购买按钮一并置灰）/ 已售（货架空位）/ 融化中（香皂专属）。
- **同一张卡共用**于所有出场场景，仅尺寸变化：道具栏（小）、商店 / 黑市货架（中，价格在卡外）、
  发现三选一（大）、使用飞出动画（大）。

> **卡面文案规范**（2026-10-01 定稿）：描述为**炉石风味的玩家视角短文案**，
> 只写玩家需要知道的一句话机制；概率、池过滤等细节以 `道具图鉴.md` 为准，不上卡。
> **一次性道具统一尾句「每局游戏仅限一次」**。
>
> **图案管线**（2026-10-02 起；现 **68 件**全有 `icon`，初稿时是 61 件）：`item_data` 每件一个 `icon` 字段 →
> `assets/icons/item_*.png`（256px；Twemoji 14.0.2 SVG 经 Godot 烘焙，双 emoji 的用 PIL 合成；

## 十、与其他系统的接口

- **小卖部 / 黑市**：道具即货架商品。铺货与售价见 `小卖部.md`，以地皮计价见 `黑市.md`。
- **机会卡**：`进入小卖部`、`获得道具`、`进入黑市` 三类**效果字段**是道具与商店的接口；
  抽卡本身分**三类卡**（机会卡 / 道具卡 / 畸变卡），见 `机会卡.md`。
- **科技 / 畸变**：科技池见 `科技.md`；畸变可作**道具闸门**——如「诚信考试」本回合封禁道具使用
  （只封使用，冷却照常计时、自动补充照常到账），见 `畸变.md`。
- **开局设置**：起始资金等写死常量收拢到「设置对象」，见 `开局设置.md`。
- **公开性**：体力与冷却公开显示；**背包对所有人公开**（定稿——看得到对手攥着什么才有博弈）。
- **破产观战**：破产者清空道具（唯一道具回池），且不可再用道具。
- **托管**：超时由系统兜底；休眠 = 强制保守托管，见 `回合与行动.md`。
- 全部道具状态由**房主权威**维护，客户端只发请求，见 `development/架构总览.md`。

## 十一、设计待定

- **数值专场**：焦土捐款额与恢复目标比例；小卖部刷新价曲线（是否封顶 / 是否整局不重置）；各档售价是否再调。
- **预告待落定**：被动道具「可以选择进不进店」。
- **香皂融化贴图**：由 10 回合剩余数驱动的分段表现，正式素材待美术，交接接口为「剩余回合数 → 贴图档位」。
- **卡片模板**：待确认后接入道具栏 / 货架 / 发现三选一。
- **占位道具**：不再编造假金货（四件真金货够测顶档管线），占位只补白 / 蓝空位。
