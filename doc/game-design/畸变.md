# 畸变（全场事件）

> 游戏进行过程中触发的**全场效果**，对全部存活玩家生效。开关、触发频率与持续回合
> 由房主开局设置决定（见 `开局设置.md`）；与道具的交集见 `道具系统.md`，香皂见 `道具图鉴.md`。

## 一、定义

- 畸变是**游戏进行过程中**触发的**全局效果**，对**全部存活玩家**生效。
- 触发方式两种：**随机触发**（按频率掷概率）或**满足条件后触发**。
- **debuff 型畸变可被「空想者的香皂」抵消**（逐玩家独立判定）。
- 触发频率与持续回合均可由**房主开局设置**调整。
- 类型分**持续型**与**非持续型**。

## 二、触发

- **时机**：在**回合开始**结算；与体力 / 冷却 / 香皂 / 信托基金的先后见 §五。
- **随机触发**：开启后按「触发频率」每回合掷概率（关 / 低 / 中 / 高）。
- **条件触发**：满足条目预设条件时触发（如「首次有人持有 5 块及以上地皮」）。
- **表现**：横幅公告 + 全员角标；非持续型结算即时反馈（飞字 / 飘字）。

## 三、类型

| 类型 | 含义 | 判定 | 例 |
|---|---|---|---|
| **持续型** | 在**持续回合**内某条规则被持续改写；期间显「生效中」状态 | 每回合 / 每步判定 | 诚信考试 |
| **非持续型** | 触发**瞬间结算**，或排队**一次性规则改动**（跨回合但不构成持续状态） | 结算一次 | 金融危机、调休 |

> 判定归属由设计者指定；「调休」虽跨两回合，仍归**非持续**（排队的单次改动，非持续改写）。

## 四、标签与香皂

- **debuff 畸变**：**逐玩家独立**被香皂免疫；持续型的持皂者在**整个持续期内**免疫。
- **buff / 中性畸变**：香皂**无效**。
- 每个条目**显式标注**标签，运行时据此判定（标签体系见 `道具系统.md`）。

## 五、结算顺序

回合开始现有顺序：**体力 +1 → 冷却 −1 → 香皂融化 → 信托基金**。
畸变触发插在**回合开始结算之后、掷轮之前**；持续型状态在整回合内生效。
畸变闸门与「每回合限次 / 冷却 / 体力」三闸并列。

## 六、房主设置

| 项 | 默认 | 说明 |
|---|---|---|
| 畸变开关 | 关 | 关闭则整局不触发 |
| 触发频率 | 低 | 关 / 低 / 中 / 高（随机触发概率） |
| 持续回合 | 2 | 持续型畸变的默认时长基准（条目可覆盖） |
| 条件触发 | 开 | 是否允许条件型畸变触发 |

## 七、图鉴

| 名称 | 类型 | 触发 | 效果 | 标签 | 香皂 | 设计状态 |
|---|---|---|---|---|---|---|
| 诚信考试 | 持续 | 随机 | 本回合所有玩家不能使用道具 | debuff | 免疫 | 定稿 |
| 金融危机 | 非持续 | 随机 | 所有玩家损失自身现金的 XX%，有房产者更多 | debuff | 免疫 | 草案 |
| 调休 | 非持续 | 随机 | 本回合不能转盘；下一回合可转两次 | 中性 | 无效 | 草案 |

### 诚信考试（持续 · debuff）

- **效果**：本回合**所有玩家不能使用道具**。
- **边界**：只封「使用」；**冷却照常计时、自动补充照常到账**。
- **香皂**：不利项是 debuff，皂党不被封锁（本回合照常可用道具）。

### 金融危机（非持续 · debuff）

- **效果**：触发瞬间，**所有存活玩家**损失**自身现金**的 XX%：
  - **无房产**：损失 XX%（建议 10%）；
  - **有房产**：损失 YY%（建议 20%），或按持有地产数量递增。
- 扣完若现金不足，按破产规则结算。
- **香皂**：debuff，持皂者**不被扣**（逐玩家独立）。
- **边界**：只动现金、不动地产（避免连锁处置）。

### 调休（非持续 · 中性）

- **效果**：**本回合**所有玩家**不能转动转盘**（不移动、不结算落点）；**下一回合**可**转动两次**。
- **定性**：中性（规则改动，非 debuff）；香皂无效。

## 八、候选（草案）

> 以下为补充设计，供挑选；确认后再升入 §七 图鉴。

**持续型**

| 名称 | 效果 | 标签 |
|---|---|---|
| 停电 | 持续期内小卖部 / 黑市**不可进入**（落店 = 路过） | 中性 |
| 通胀 | 持续期内全场**租金 ×2** | 中性 |
| 限电 | 持续期内每回合开始**体力不再 +1** | debuff |
| 隔离 | 持续期内所有玩家**移动点数 −2**（下限 0） | debuff |
| 奖学金季 | 持续期内每回合开始所有玩家 **+¥300** | buff |

**非持续型**

| 名称 | 效果 | 标签 |
|---|---|---|
| 天降红包 | 所有玩家 **+¥500** | buff |
| 强制捐款 | 所有玩家各**扣 ¥500**（学校收走） | debuff |
| 集体感冒 | 所有玩家**下一回合休眠** | debuff |
| 拆迁 | 全场**随机 1~2 块地皮变无主** | debuff |

**条件触发**

| 名称 | 触发条件 | 效果 | 标签 |
|---|---|---|---|
| 房价崩盘 | 首次有人持有 **5 块及以上**地皮 | 全场**租金减半** N 回合 | 中性 |
| 枪打出头鸟 | 某玩家现金首次超过 **¥X** | 其**强制捐款 XX%** | debuff |

## 九、设计待定

- 触发频率概率表（关 / 低 / 中 / 高 → 具体数值）。
- 持续回合的默认值与条目覆盖规则。
- 横幅 + 全员角标 + 非持续结算的表现形式。
- 图鉴扩充条目定稿（§八 候选）。
- 数值回填：金融危机的 XX% / YY%，条件触发的 X / XX%。
- 调休与道具系统的联动、与转轮 12 / 作弊器 / 点名的叠加规则。
