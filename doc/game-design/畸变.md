# 畸变（全场事件）

> 游戏进行过程中触发的**全场效果**，对全部存活玩家生效。开关、触发频率与持续回合
> 由房主开局设置决定（见 `开局设置.md`）；与道具的交集见 `道具系统.md`，香皂见 `道具图鉴.md`。

## 一、定义

- 畸变是**游戏进行过程中**触发的**全局效果**，对**全部存活玩家**生效。
- 触发方式两种：**随机触发**（按频率掷概率）或**满足条件后触发**。
- **debuff 型畸变可被「空想者的香皂」抵消**（逐玩家独立判定）。
- 触发频率与持续回合均可由**房主开局设置**调整。
- 类型分**持续型**与**非持续型**。

## 二、触发

- **时机**：在**回合开始**结算；与体力 / 冷却 / 香皂 / 信托基金的先后见 §五。
- **随机触发**：开启后按「触发频率」每回合掷概率（关 / 低 / 中 / 高）。
- **条件触发**：满足条目预设条件时触发（如「首次有人持有 5 块及以上地皮」）。
- **表现**：横幅公告 + 全员角标；非持续型结算即时反馈（飞字 / 飘字）。

### 触发限制（2026-10-04 定稿）

- **闸门一 · 每回合最多触发 1 条新畸变**：回合开始的畸变窗口内只发一条。
- **闸门二 · 全场同时最多 1 条持续型「生效中」**：有持续型还在生效时，本回合窗口整体跳过——
  随机候选丢弃、条件候选照常顺延。
- **候选挑选**：收集本轮所有够格候选（随机掷中 + 条件达成）后只挑一条：
  **条件触发 > 随机触发**；同级按图鉴顺序 + 掷骰决出。
- **落选处置**：条件型**顺延**——插队到下一回合窗口候选最前、优先补发，顺延队列**上限 2 条**、
  超出丢弃；随机型**本轮作废**，下轮重新掷。
- **非持续型不占闸门二**（无「生效中」状态，两条非持续型前后脚触发允许）。
- **目标细则**：带目标的条件型多人同回合达标时，取现金最高者，并列掷骰；顺延补发同样过两道闸。
- **实现收口**：全部逻辑收在回合开始畸变窗口一个函数（收集 → 过滤 → 挑选 → 顺延），
  房主权威，客户端只看广播。

## 三、类型

| 类型 | 含义 | 判定 | 例 |
|---|---|---|---|
| **持续型** | 在**持续回合**内某条规则被持续改写；期间显「生效中」状态 | 每回合 / 每步判定 | 诚信考试 |
| **非持续型** | 触发**瞬间结算**，或排队**一次性规则改动**（跨回合但不构成持续状态） | 结算一次 | 金融危机、调休 |

> 判定归属由设计者指定；「调休」虽跨两回合，仍归**非持续**（排队的单次改动，非持续改写）。

## 四、标签与香皂

- **debuff 畸变**：**逐玩家独立**被香皂免疫；持续型的持皂者在**整个持续期内**免疫。
- **buff / 中性畸变**：香皂**无效**。
- 每个条目**显式标注**标签，运行时据此判定（标签体系见 `道具系统.md`）。

## 五、结算顺序

回合开始现有顺序：**体力 +1 → 冷却 −1 → 香皂融化 → 信托基金**。
畸变触发插在**回合开始结算之后、掷轮之前**；持续型状态在整回合内生效。
畸变闸门与「每回合限次 / 冷却 / 体力」三闸并列。

## 六、房主设置

| 项 | 默认 | 说明 |
|---|---|---|
| 触发频率 | 关 | 关 / 低 / 中 / 高（**「关」即总开关关闭**，2026-10-04 实现时与原「开关」项合并为一项；低/中/高的每回合概率为占位值） |
| 持续回合 | 2 | 持续型畸变的默认时长基准（条目可覆盖），**按玩家回合数计**（2026-10-04 拍板） |
| 条件触发 | 开 | 是否允许条件型畸变触发 |

> 入口：对局内暂停菜单 → 设置面板（房主可改、客户端只读、随快照同步）；
> 大厅开局入口随「开局设置面板」批次接入。

### 诚信考试（持续 · debuff）

- **效果**：本回合**所有玩家不能使用道具**。
- **边界**：只封「使用」；**冷却照常计时、自动补充照常到账**。
- **香皂**：不利项是 debuff，皂党不被封锁（本回合照常可用道具）。

### 金融危机（非持续 · debuff）

- **效果**：触发瞬间，**所有存活玩家**损失**自身现金**的 XX%：
  - **无房产**：损失 XX%（建议 10%）；
  - **有房产**：损失 YY%（建议 20%），或按持有地产数量递增。
- 扣完若现金不足，按破产规则结算。
- **香皂**：debuff，持皂者**不被扣**（逐玩家独立）。
- **边界**：只动现金、不动地产（避免连锁处置）。
- **实现备注**：占位 10% / 20% 落在 `AberrationData.FIN_RATE_NC / FIN_RATE_C`；「按地产数递增」的曲线未做。

### 调休（非持续 · 中性）

- **效果**：**本回合**所有玩家**不能转动转盘**（不移动、不结算落点，道具阶段照常）；当前玩家**自己的下一回合连转两次**（2026-10-04 拍板口径）。
- **定性**：中性（规则改动，非 debuff）；香皂无效。

### 停电（持续 · 中性）

- **效果**：持续期内小卖部 / 黑市**不可进入**（落店 = 路过，不触发商店界面）。
- **香皂**：中性，无效。

### 通胀（持续 · 中性）

- **效果**：持续期内全场**租金 ×2**（付租方多付、收租方多收，向下取整）。
- **香皂**：中性，无效。
- **联动/备注**：与租金修正类道具（保安巡逻 / 招财猫）的叠加顺序待实现复核。

### 限电（持续 · debuff）

- **效果**：持续期内每回合开始**体力不再 +1**。
- **香皂**：debuff，逐玩家独立——持皂者照常 +1。

### 隔离（持续 · debuff）

- **效果**：持续期内所有玩家**移动点数 −2**（下限 0；转轮 0 待命不叠加）。
- **香皂**：debuff，逐玩家独立——持皂者移动不受减。

### 奖学金季（持续 · buff）

- **效果**：每名玩家在**自己的回合开始**时 **+¥300**（2026-10-04 拍板口径，相当于全局版信托基金）。
- **香皂**：buff，无效。

### 天降红包（非持续 · buff）

- **效果**：触发瞬间所有存活玩家 **+¥500**。
- **香皂**：buff，无效。

### 强制捐款（非持续 · debuff）

- **效果**：触发瞬间所有玩家各**扣 ¥500**（学校收走）；付不出按破产（变卖保底）规则结算。
- **香皂**：debuff，逐玩家独立——持皂者不被扣。

### 集体感冒（非持续 · debuff）

- **效果**：触发后所有玩家**下一回合休眠**（被动照常、保守托管）。
- **香皂**：debuff，逐玩家独立——持皂者不受休眠。

### 拆迁（非持续 · debuff）

- **效果**：触发瞬间全场**随机 1~2 块地皮变无主**（等级清零、可被再购买）。
- **香皂**：debuff，逐受害者独立——被抽中地皮的现任地主持皂则该块不拆（是否改抽其他地块待实现定）。

### 房价崩盘（持续 · 条件触发 · 中性）

- **触发条件**：首次有玩家持有 **≥5 块**地皮（回合开始窗口检测）。
- **效果**：全场**租金减半**（向下取整），持续 **N 回合**（N 待数值专场）。
- **香皂**：中性，无效。
- **联动/备注**：租金减半与通胀 ×2 同屏互斥（闸门二保证）；与道具租金修正的叠加顺序待实现复核。

### 枪打出头鸟（非持续 · 条件触发 · debuff）

- **触发条件**：某玩家**现金首次超过 ¥X**（回合开始窗口检测；X 待数值专场）。
- **效果**：该玩家按现金的 **XX%** 强制捐款（XX 待数值专场）。
- **香皂**：debuff，持皂者免疫。
- **多人同回合达标**：取现金最高者，并列掷骰（见 §二触发限制）。
