# 事件卡（机会 / 命运）

> 落在事件格抽一张卡，按卡字段结算。畸变是另一套全场系统，见 `畸变.md`；
> 效果标签体系见 `道具系统.md` 的「效果标签」。

## 一、抽卡

- 落在地图格型 `event` 上 → 从**对应牌堆**（「机会」或「命运」）抽一张，中央牌堆有抽卡动画。
- 卡池 = 通用卡（无 `only`）+ `only` 命中当前格类型的专属卡。
- 当前棋盘只有 1 个「机会」格、1 个「命运」格；专属卡**只在机会格出现**。

## 二、卡字段（数据契约）

| 字段 | 含义 |
|---|---|
| `t` | 卡面文本 |
| `money` | 收支（正数入账；负数扣钱，**可被香皂免疫**） |
| `from_each` | 每位**其他存活**玩家给你该金额（受害者逐人独立免疫） |
| `to_each` | 你给每位其他存活玩家该金额（你持皂则整条免疫） |
| `move_steps` | 前进 / 后退若干格（负数倒退；途中踏过起点照常领工资；**移动后照常结算落点**；后退可被香皂免疫） |
| `go_jail` | 直接送宿委会（可被香皂免疫） |
| `enter_shop` | 进入一家随机小卖部 |
| `gain_item` | 获得指定 id 道具（背包满作废） |
| `gain_item_quality` | 随机获得一件指定品质道具（唯一池过滤；缺货 / 满包作废提示） |
| `enter_blackshop` | 进入黑市（见 `黑市.md`） |
| `only` | 只在指定格类型出现（如 `"机会"`） |

## 三、结算顺序

依次处理：`money → from_each → to_each → go_jail → move_steps → gain_item / gain_item_quality → enter_shop → enter_blackshop`。

- `move_steps` 走完后**照常结算落点**——所以「前进 X 格」可能又触发一张事件卡或买地，属设计内。
- 卡型配色按效果分 good / bad / move / jail / info 五类。

## 四、免疫点

| 效果 | 标签 | 香皂 |
|---|---|---|
| `money` 负数、`to_each`、`go_jail`、`move_steps < 0` | debuff | 免疫 |
| `from_each` 扣受害者 | debuff | **逐受害者**独立免疫 |
| `money` 正数、`gain_item*` | 中性 | 不受影响 |

## 五、当前卡池概览

- **通用卡**（机会 / 命运共享）：约 33 张，涵盖 ±金额、前进 / 后退、送监、红包、请客，以及**获得道具**（`gain_item_quality`：失物招领白件 / 社团抽奖绿件 / 学长清仓蓝件）。
- **机会专属卡**：
  - 路过小卖部（`enter_shop`）
  - 公告栏道具券（`gain_item_quality: 蓝`）
  - 神秘短信（`enter_blackshop`）

## 六、设计待定

- 更多机会专属卡与卡池扩展（`only` 机制已就绪）。
