## 一、目标与命名

用户原话三项：

1. 所有事件卡统一为「**机会卡**」，棋盘图格统一改「**机会**」，**去掉桌面上的两摞牌堆**。
2. 走到机会格：**85% 机会卡 / 10% 道具卡 / 5% 畸变卡**。
3. 审查并重设计机会卡，**增至 50 张**，智斗比例高，不能全是给钱/扣钱。

定下的口径：

- 棋盘 4 个 `event` 格**全部命名「机会」**（格型仍是 `event`），图标统一 `luck`（现有
  `TILE_ICONS["event"]` 的 `{"机会": "luck", "命运": "fate"}` 字典摊平成一个字符串）。
- 三类卡统称**事件卡**（术语表保留这个词做统称）；主卡类叫**机会卡**。
- 文档 `doc/game-design/事件卡.md` → **改名 `机会卡.md`**（机制 + 50 张卡表都在这一份，
  单一来源）；全仓库约 40 处引用同步。
- **删掉 `only` 字段与「命运」**。**保留**「按开局开关过滤卡池」那条逻辑：
  黑市未开 → 不发 `enter_blackshop` 卡；小卖部关 → 不发 `enter_shop` 卡；滤空则回退全池。

## 二、抽卡：一次判定，三类结果

落在机会格 → **先掷类别，再按类别取值**（概率精确，不靠牌堆配比拼出来的近似值）。

| 档 | 概率 | 结算 |
|---|---|---|
| 机会卡 | 85% | 从**统一的机会牌堆**抽一张（预生成洗牌、抽空补洗，沿用现有 `_event_decks` 机制） |
| 道具卡 | 10% | **按品质权重随机得一件**（新增权重表 `GameData.CHANCE_ITEM_WEIGHTS`；唯一池过滤 / 缺货降档 / 满包作废，口径与现有 `gain_item_quality` 一致） |
| 畸变卡 | 5% | **从现有畸变池随机抽一条，全场立即生效** |

### 边界规则（三条，用户已认可）

1. **畸变总开关 =「关」**（`开局设置.md` 的触发频率「关」）时，5% 档作废 → **改发机会卡**
   （实际分布 90/10/0）。理由：畸变被房主关掉，机会格不该绕过设置把它塞回来。
2. **畸变卡池** = `AberrationData.ABERRATIONS` 里 `implemented == true` **且 `trigger == "随机"`
   且满足 `min_round`** 的条目。**条件型不进池**（「房价崩盘」「枪打出头鸟」靠条件检测触发，
   硬抽会很怪，且它们的 `cond` 语义要求有触发主体）。
3. **持续型撞车 = 新盖旧**：抽到持续型畸变、而场上已有持续型生效中时，**提前结束旧的那条**，
   保住「全场同时最多 1 条持续型」不变量。
4. **绕过两道闸门**（这是设计内的例外，须写进 `畸变.md`）：玩家中途抽卡不属「回合开始的畸变
   窗口」，因此不受闸门一（每回合最多 1 条）与闸门二（同时最多 1 条持续型）约束 —— 闸门二
   靠上面第 3 条用「新盖旧」兜住。

概率**写死为 `GameData` 常量**（`CHANCE_P = 0.85` / `CHANCE_ITEM_P = 0.10` / `CHANCE_AB_P = 0.05`），
**不进开局设置**（用户 2026-10-09 拍板：YAGNI，将来要调档位再说）。

### 与现有科技的交界

- 厄运保单（科技 14）只认 `money` 负数 → 新增字段**不触发**（避免语义漂移）。
- 喜报频传（科技 21）只认 `money` 正数 → 同上。
- 小抄（道具）文案「偷看**命运**牌堆的下一张卡」→ 改为「偷看**机会**牌堆的下一张卡」，
  实现改 `_peek_event("机会")`。注意：牌堆只装机会卡，所以小抄看不到「这次会不会抽中道具/畸变」
  —— 语义上是一次**轻微削弱**，写进 `道具图鉴.md`。

## 三、数据契约

沿用现有架构：**一张卡 = 一个字段字典**，`_apply_card` 按固定顺序分派（不引入 effect 对象 ——
图鉴生成器 `tools/gen_gallery.gd` 复用同一份 `GameData.card_kind()`，改成对象就会多出第二来源）。

### 3.1 新增字段（15 个）

| 类 | 字段 | 含义 |
|---|---|---|
| 指定目标 | `steal_from: int` | 从选定目标夺取现金（不足则取其所有） |
| | `charge_to: int` | 向选定目标收取现金（文案区分于夺取） |
| | `jail_to: true` | 送选定目标去宿委会（他跳过下一回合） |
| | `each_from_target: int` | 选定目标给每位其他存活玩家该金额 |
| | `steal_item_from: true` | 从选定目标随机夺一件道具（自己背包满则作废） |
| 地皮与位置 | `seize_tile: "take"\|"swap"` | `take` 夺目标一块投入最少的地（含装修等级）；`swap` 与目标各随机一块互换（无地则作废） |
| | `force_buy_tile: int` | 以该百分比原价强买目标一块地（投入最少的一块；现金不足作废） |
| | `swap_pos: true` | 与目标交换棋子位置（**不结算落点、不领工资**） |
| | `pull_target: true` | 把目标拉到你当前格（他**照常结算落点**） |
| | `push_back: int` | 目标后退 N 格（照常结算落点） |
| | `shuffle_pos: true` | 全场玩家位置**随机重排**（无目标） |
| 抉择与情报 | `choices: Array` | 二选一（最多 3 项），每项 `{t: 选项文案, …效果字段}` |
| | `peek_deck: int` | 私密偷看机会牌堆顶 N 张 |
| | `shuffle_deck: true` | 重洗机会牌堆（作废所有人的预知） |
| | `bury_deck: true` | 把机会牌堆顶一张塞到底部（跳过一张） |

### 3.2 结算顺序

现有链：`money → from_each → to_each → go_jail → move_steps → gain_item / gain_item_quality
→ enter_shop → enter_blackshop`。

新增字段**插在 `go_jail` 之后、`move_steps` 之前**（先定点打击、再位移）：
`… → go_jail → [目标类 → 地皮类 → 情报类] → move_steps → …`。

- 目标类内部顺序：`steal_from → charge_to → each_from_target → steal_item_from → jail_to`。
- 位移与落点：`swap_pos` / `shuffle_pos` **不结算落点**（纯换位）；`pull_target` / `push_back`
  **照常结算落点**（与 `move_steps` 同口径，可能连环触发）。

### 3.3 免疫（香皂）口径

| 字段 | 标签 | 香皂 |
|---|---|---|
| `money` 负数、`to_each`、`go_jail`、`move_steps < 0` | debuff | 抽卡者持皂**免疫**（现状不变） |
| `steal_from`、`charge_to`、`jail_to`、`each_from_target`、`steal_item_from`、`seize_tile:"take"`、`force_buy_tile`、`pull_target`、`push_back` | debuff | **目标**持皂则整条免疫 |
| `seize_tile:"swap"`、`swap_pos`、`shuffle_pos`、`peek_deck`、`shuffle_deck`、`bury_deck` | 中性 | 无效 |
| `money` 正数、`gain_item*` | 中性 | 无效（现状不变） |
| `choices` | 按所选分支**逐项**判定 | 同上 |

### 3.4 选目标与抉择的交互

- **选目标**：复用现有 `_tgt_stage == "peer"` 那套（立牌 / 名册条点亮，批次 13 ②）。
  合法目标按字段过滤：`seize_tile` / `force_buy_tile` 只列**名下有地**的玩家（口径同「强拆令」）；
  其余列所有其他存活玩家。bot 自动选（现金最多 / 地最多）；超时走现有兜底。
- **抉择**：卡面演出给 1~3 个按钮，新增 **`c_choice`**（客户端→房主）提交所选项，
  房主结算。bot 按策略选；超时取第一项。
- **两级组合**（如「告密还是包庇」：两个分支都要选目标）：先选分支、再选目标，共两次交互。

### 3.5 表现层配套

- `GameData.card_kind()` 扩展新卡的卡型配色（现有 good/bad/move/jail/info 五类；目标类按
  对抽卡者有利 → good，纯侵夺 → 沿用 bad/good 规则）。生成器读同一份，不另抄。
