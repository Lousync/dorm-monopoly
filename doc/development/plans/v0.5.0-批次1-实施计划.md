# v0.5.0 批次 1 实施计划：撤设施 + 删转视角

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把桌面上的小卖部 / 宿舍赌场两座常驻设施撤下来（改为触发时全屏界面），并删除转视角功能——为批次 2 的 3D 桌面改造清出干净的屏幕。

**Architecture:** 表现层从「桌面世界层」搬到「屏幕层」。两座设施原本画在 `board_view` 的 `_world` 子树里（是个 `Control`，随自研 2D 相机平移/缩放/旋转），改为挂在 `game` 屏幕层的全屏模态面板——照 `menu_layer` 那一套：全屏压暗底（`mouse_filter=STOP`，负责吞掉面板外的点击）+ 居中面板，**两者一起显隐**。玩法逻辑、数值、RPC 装饰器一行不动。

**Tech Stack:** Godot 4.6.2 / GDScript / `gl_compatibility`；测试是 `extends SceneTree` 的无头脚本。

**Spec:** `doc/development/plans/v0.5.0-布局2.5D.md`（§三 构图、§四 触发式界面、§五 人与物、§八 影响面、§九 批次 1）

## Global Constraints

- **不动玩法逻辑与数值**；不动 `doc/development/联机协议.md`——`_broadcast_state` 的字段**不加不减**。
- **房主权威**：所有 `@rpc` 装饰器与方向原样保留（`s_*` 广播、`c_*` 上报、私密走 `rpc_id`）。
- GDScript、**Tab 缩进**、中文注释。
- 哨兵值：`GameData.NO_OWNER = -100`、`NO_PEER = -9999`——**不得用 -1 判空**（机器人 peer 从 -1 递减）。
- **弹层与其外层全屏容器必须一起显隐**。外层是 `set_anchors_preset(FULL_RECT)` + 默认 `mouse_filter=STOP` 的容器，只切内层 `visible` 会把整屏点击吃光（`fix/v0.1.0` 的暂停卡死真凶，见 `tests/pause_menu_test.gd`）。
- 每改完一个文件先跑 `--script tests/load_all.gd`（能抓出解析错误），再跑该任务的测试。
- 本机 Godot：`D:\Godot\Godot_v4.6.2-stable_win64_console.exe`（**必须带 `_console`**，否则看不到 stdout）。
- 摆拍截图**不能加 `--headless`**（无头下 `get_viewport().get_texture()` 是空帧）；截图前先 `mkdir -p shots`。
