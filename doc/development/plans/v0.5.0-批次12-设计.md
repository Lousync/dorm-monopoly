## 一、逐条决定

### ① 去掉台灯 + 棋盘再放大

**用户原话**：台灯先去掉；棋盘比例放大，现在字还是有点小。

**决定**：
1. **删掉台灯的全部可见几何**（`Lamp` 下的 `Base/Pole/Arm/Shade`），但**保留那盏灯本身** ——
   把它的 `OmniLight3D` 原地保留、改名为 `key_light`（同一个世界坐标 / 同一份色温 / 能量 / 衰减 /
   阴影开关）。理由：台灯**是全场唯一光源、也是唯一投影的光源**（批次 6 定案），直接删光会让
   屋子变全黑、实体影子全丢；用户要删的是"那盏碍事的灯罩"，不是"光"。
   代价（如实留痕）：**光的来源不再有可视载体** —— 观感上变成"窗外透进来的一束暖光"。
2. **棋盘放大第二档**（批次 10 已放大过一档）。台灯在画外，正好解开批次 10 那条
   「3D 端格宽被台灯可见性顶住」的上限（`layout_test` 原断言 37.6px 封顶）。目标：
   - 3D 端格宽 **37.6 → ≈44px**、2D 端 **42.8 → ≈50px**（再 +15% 量级）；
   - 手法同批次 10：收桌面留白 + 收木纹框 + 两端相机**一起**推近。
   - 初值：`MAT_MX/MT/MB` 40/40/90 → **18/18/64**、`WOOD_FRAME` 0.7 → **0.42**、
     `CAM_DIST` 4.7 → **4.15**、`VIEW_DIST_2D` 7.6 → **6.7**。**以实测定档**，不硬套。

**验收**：截图（3D / 2D 两端）+ `layout_test` 的格宽下限断言按新基线改。

### ② 小人偏暗 + 立牌 2D 视角适配

**决定**：
1. **提亮**：棋子薄牌加**自发光**（`emission` = 体色 × 0.45、能量 0.45），正面小人贴图再加一层
   弱自发光（0.25）。近黑屋子里小人这才"跳"出来。（批次 11 只给了体色、无 emission。）
2. **2D 适配 —— 薄牌随视角"躺平"**：现在薄牌**固定后倾 25°**，转到 2D 俯视（88°）就只剩一条棱。
   改为 `view_t` 驱动：`rotation.x = lerp(-25°, -90°, view_t)`
   —— 3D 端照旧后倾 25°（正脸朝镜头），2D 端**平贴桌面、正脸朝上**（就是老 2D 棋盘上那个图案）。
   **同时改为"中心锚定"**：薄牌绕自身中心摆放（原来锚在底边），否则躺平时会从格子里甩出去。
   代价（如实留痕）：3D 端小人比现在**略低一点点**（中心锚定 vs 底边锚定的差），
   属于同一次改动里的既定取舍。

### ③ 「购买地产」弹窗与「格详情」弹窗融合

**决定**：**同一个面板**（现 `TableHud.info_panel`）承担两件事 ——
1. 点图格 → 弹**格详情**（现有内容）+「买下它！/ 装修！」区（仅当**我有待决**且就是这一格时出现）；
2. 落地自动触发 → 弹**同一个面板**（带按钮 + 倒计时条），**锚在该格上方**（复用
   `_place_info_panel` 的"浮在格子上方"逻辑），**不再屏幕居中**；
3. 可以 ✕ 关掉，关掉后**再点一次该格**又出来；倒计时照走（关掉面板不等于放弃）。

**理由**：`_ask` 全仓库只有 2 个调用点（买 / 装修），所以这条只影响这两个决定，
不牵动其它弹窗。**代价**：关掉面板后玩家可能"忘了自己还没决定" —— 由**屏幕右下角动作按钮**
与倒计时条的红色预警兜底。

### ④ 转盘指针 3D 化

**决定**：删掉 `WheelView._draw()` 里那个 **2D 三角形指针**，改由 `TableProps.build_wheel` 增
一枚**平贴桌面的 3D 金箭头**（薄挤出三角 + 与轮缘同一份金材质），立在轮盘正上方、指向轮心。
**理由**：立着的指针在 2D 俯视下同样只剩一条棱（正是 ② 的病）；**平贴**的箭头两端都读得出来。
**代价**：指针不再"高过桌面"，投影感弱 —— 与轮缘同层，观感统一。

### ⑤ 手牌贴图与商店一致

**决定**：新增**卡面烘焙**（与批次 11 烘房子纹理同一手法）：把 `ItemCard.make(id, …)` 烘成
`Texture2D`，按 item id **缓存**（`UPDATE_ONCE`）。手牌正面贴这份烘焙纹理 ⇒ 与商店货架**同一张卡**。
- 烘焙尺寸取**手牌卡面比例**，`ItemCard` 的排版按传入 `size` 自适应（实现时核对；若它写死了
  偏移量，则改烘 `SIZE_MEDIUM` 再等比铺满）。
- **代价**：每件道具多一个 300×420 的 SubViewport（约 60 件，惰性建、按需烘）；
  手牌从"一色块 + 一个图标"变成"一张完整的卡"，更贴用户预期。

### ⑥ 房子太小太暗 + 2D 视角适配

**决定**：
1. **放大**：房子的宽高从"跟着印刷图案"改为 **印刷图案 × 1.3**（`HOUSE_SCALE = 1.3`）；
2. **提亮**：`_house_body_mat` 加自发光（0.35），四张等级纹理的材质也加一层弱自发光（0.3）；
3. **2D 适配**：与 ② 同一套 `view_t` 躺平 + 中心锚定。

### ⑦ 玩家信息弹窗显示完整卡牌

**决定**：`PlayerPopup._item_row` 从"30×30 小图标 + 名字"改成**一整张卡**（用 ⑤ 的烘焙纹理，
约 120×160），名字与状态标签（被动 / 冷却 N / 未实装）挂在卡下面，整块**换行排布**（`FlowContainer`）。
**代价**：弹窗变高、道具多时要滚动 —— 用 `ScrollContainer` 兜住。

### ⑧ 抽卡动画 / 小卖部对所有人可见 + 卡片加「确定」

**查明的事实**：**抽卡动画本来就已经全员可见**（`s_card` 是 `call_local` 广播、无 `rpc_id` 过滤）；
**只有小卖部**是"仅落地者可见"。

**决定**：
1. **小卖部改为全员可见**：`shop_layer.visible` 的门槛从「`shop_peer == my_peer`」改成
   「`shop_open >= 0`（有人正在逛）」；**只有本人**的货架可点（他人视角**只读**：按钮变灰、
   加一条「XX 正在挑选」的说明条）。
2. **卡片加「确定」**：`DeckReveal` 停在 HOLD 之后**不再自动收**，改出**「确定」按钮**；
   **由"该玩家"点**（抽卡者 / 需要确认的人）。点后：房主广播关闭 ⇒ 全员收起。
   - 新增一对 RPC：`c_card_ok`（客户端→房主）/ `s_card_close`（房主→全员）。
   - **超时**走既有操作限时挡位（`_await_turn_window` 那一套），到点自动确认；
   - **机器人 / 休眠托管**：短暂延时后自动确认（不卡节奏）。
   - 观众（非抽卡者）看到同一张卡、**没有按钮**（或按钮禁用），由抽卡者的确认统一收起。
   **代价**：每次机会/命运卡多一次点击 —— 这是用户明确要的；用超时与托管兜住节奏。

### ⑨ 鼠标经过手牌放大

**决定**：把 `TableView3D.on_table_hover` 的命中从"只看小人"扩到**也看手牌**
（`TableProps.hand_hit` 已有），悬停的那张 `set_hand_hover(i)`：**放大 1.12 + 抬起 0.06 +
略微前倾**，`Tween` 过渡 0.12s；移开还原。

### ⑩ HUD 重排（他人信息框 / 规则说明 / 我的能量 / 转动转盘）

**决定**：
1. **删掉"他人"的四角身家条**，只留**我自己**那条（BOTTOM_LEFT）；
2. 他人信息改为**顶部一条常驻名册条**（徽记 + 名字 + 身家，**置顶**、与战报同区），
   **点一条 = 开该玩家的道具弹窗**；
3. ⚠ **选目标的落点跟着搬**：批次 9 起"选目标 = 点对手的四角身家条"。四角条删了之后，
   **名册条接管选目标**（可选中者描金边，与行动者 1px 金边分得开）—— **这条不搬，选目标就没落点了**；
4. **「规则说明」按钮搬到右上角**，与「战报」并列；
5. **我这条身家条加一行「能量」（体力）**；
6. **「转动转盘」按钮固定在右下角**（原就在右下，与"删掉右下身家条"腾出的位置对齐，微调到更贴角）。

### ⑪ 失物招领加道具抽卡动画

**决定**：复用 ⑧ 的抽卡演出 —— 落地捡到道具时，`DeckReveal` 演**这张道具的卡面**（⑤ 的烘焙纹理），
与机会/命运**同一段四相位 + 同一个「确定」按钮 + 同一条超时/托管**。
**代价**：`show_card` 要多认一种"卡源"（牌堆 vs 道具卡面）。

### ⑫ 畸变显示框移中间

**决定**：`ab_label` 从 `PRESET_TOP_RIGHT` 改为**水平居中**、仍在屏幕上方（toast 之上，
`y ≈ 6..48`）。**理由**："中间"= 不再贴右上角；真放屏幕正中会盖住棋盘中心与格详情卡。
**验收**：截图确认不与战报气泡 / 名册条打架。

## 二、跨条约定

- **不动玩法逻辑与数值**；`s_state` 字段**只增不减**（⑧⑪ 新增卡片确认所需的字段）。
- **新增 @rpc 仅 ⑧⑪ 那一对**（`c_card_ok` / `s_card_close`），并在 `联机协议.md` 登记。
- **不动**桌垫上印刷的图案与 `tile_screen_pos`。
- 新增**素材为零**（卡面/箭头/指针全程序化或烘焙）；`LICENSE` 不动。
- GDScript、Tab 缩进、中文注释；持续动画手写 `_process`，一次性过渡用 `Tween`。

## 三、分批（4 批，各自可独立验收 + 截图）
