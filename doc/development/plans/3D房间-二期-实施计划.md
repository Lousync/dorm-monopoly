**Goal:** 让四把椅子上坐上人（3 个可见角色 + "我"不渲染），带骨骼动画：待机 + 四个玩法事件反应
（出牌 / 付钱 / 被抢地 / 破产），且**不许拖慢"读棋盘"那一档**、**不许碰玩法**。

**Architecture:** 角色是**独立的一层新场景对象**（新文件 `scripts/chars.gd`），

动画随取景淡出并**停播**，使"读棋盘"档的算力开销归零。

**Tech Stack:** Godot 4.6.2 / GDScript；素材 = **Kenney「Blocky Characters 2.0」（CC0，GLB）**
—— **Task 0 已定案**：18 个模型 / 27 条**节点变换**动画 / **无骨骼**（是 6 块刚体分件）。

## Task 0 的结论（**2026-10-06 已结清 —— 两条未知事实都有答案了**）

> 权威来源：`doc/development/chars-导入与动画普查.md`（449 行，逐条实测，
> 含"我们自己的探针出过一个假阴性"的自我更正）。下面只记**影响计划的结论**。

| 问题 | 答案 |
|---|---|
| **导入通路** | **Kenney「Blocky Characters 2.0」（CC0，包内自带 GLB）** ⇒ Godot 4.6 **原生导入、零 ERROR/WARNING**，**`project.godot` 不必动**（不需要 `blender_path`）。**FBX / `.blend` 那三条备选路全部作废**（要解决的问题不存在）。**"只有 1 个模型换 4 色"的代价估计也是错的 —— 包里有 18 个模型** |
| **有没有骨骼** | **没有 `Skeleton3D`** —— 它是「6 块刚体分件（`root` / `leg-left` / `leg-right` / `torso` / `arm-left` / `arm-right` / `head`）+ `AnimationPlayer` 动**节点变换**」。**能摆、能播**，只是摆法是 `rotation` / `scale` 而不是 `set_bone_pose` |
| **动画清单** | **27 条**（18 个模型共用同一套），**全部 `loop_mode = LOOP_NONE`**（glTF 没有循环标记、导入器不替你标） |
| **有没有坐姿** | **有 `sit` 但它不是"坐椅子"**（腿是一整块刚体、无膝关节，`sit` 把腿**平举** ⇒ 按一期椅子比例会**捅进桌子 1.66 世界**）⇒ **改手摆**：`root.y = -0.2` + `leg-*.scale.y = 0.8`，**已实测跑通**（脚正好落地、髋正好落座面） |
| **朝向** | **正面 = `+Z`**（量出来的，两处独立佐证）⇒ **与 `seat_anchor(slot)` 正好对齐、不用补 180°** |
| **比例** | **与一期家具不是同一个比例族**（家具 1 单位 ≈ 1.95 m，这个包 1 单位 ≈ 0.65 m）⇒ **`FURNITURE_SCALE = 10.0` 绝不能复用**（×10 的人有 5.4 m 高）。二期用 **`CHARS_SCALE := 2.8125`** |
| **性能** | **"骨骼蒙皮"那个风险不存在**（没有蒙皮：6 块刚体网格 + 每条 8 轨道、最多 39 帧） |

**⇒ 由此新增一条硬约束（普查带出的坑）**：包的材质是 **`KHR_materials_unlit`** ⇒ Godot 导成
`SHADING_MODE_UNSHADED`，**不响应一期的光照契约**；而**不能照抄 `room.gd` 的材质覆盖**
（那会**抹掉角色的贴图**）⇒ 二期要**另写一个只调光照参数、不碰贴图的辅助函数**，
并写一条断言钉住"角色材质不是 `UNSHADED`"。
