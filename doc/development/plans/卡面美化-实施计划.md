# 卡面美化 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把三类事件卡（机会 / 道具 / 畸变）的**卡面语言**统一成「**家族认框、卡型认章**」：
卡背 / 正面外框 / 标题 / 光晕 / 家族徽章 = **家族三色**（机会绿 / 道具蓝 / 畸变紫）；
卡型五色退出外框、只留在**右上卡型徽章**（图标 + 中文 + 色三通道）；
顺手把 `"机会"` 这个**既是配色键又是卡类名**的纠缠解掉，并把三处各写一套的配色表合成单一来源。

**Architecture:** 全在**屏幕层抽卡演出**这一处动，零 RPC 改动、零调用点改动、零素材新增。
四件事：
① **解纠缠**（`show_card` 里三行显式派生家族键；`_deck_back_tex` / `_make_card_art` / `_card_face_back`
改吃家族键、删掉 `deck == "机会"` 三元判断）；
② **两张表**（`GameData.CARD_FAMILIES` 家族表 + `GameData.CARD_KINDS` 卡型表 = 展示映射的单一来源，
演出 / `UIKit.card_palette` / 图鉴生成器全读它）；
③ **卡面本体**（文字卡正面改家族色 + 两枚骑在卡边外的徽章 + 标题粗体顶部对齐 + 分隔线两端渐隐）；
④ **道具族的统一**（卡背走蓝家族 + 一圈家族色外发光，**且那圈光只能由 `DeckReveal` 加在 `ItemCard`
外面** —— `ItemCard` 是共用件）。

**Tech Stack:** Godot 4.6 / GDScript（Tab 缩进、中文注释、静态类型）；headless 测试 `tests/*.gd`；
摆拍 `scripts/dev_tools.gd` 的 `take_shot`；图鉴生成器 `tools/gen_gallery.gd`。

**Spec:** `doc/development/plans/卡面美化.md`（已定稿、已用基准图校正）。
**本文件与它都随本版本合入 `main` 后删除**（`AGENTS.md` §五）——结论落点是
`doc/game-design/机会卡.md` §三 / `doc/game-design/道具系统.md` §九 / `doc/development/联机协议.md`
的 `s_card` 行 / `doc/game-design/设计决策留痕.md`（见 T6）。

**分支**：当前 `feature/0.15.0`（已开，直接在其上做，不再新建）。

## Global Constraints（七条硬约束 + 两条实测坑 —— 每条都落成"守不住就红"的判据）

1. **`GameData.card_kind()` 的判定顺序是契约**（`jail_to` 先于 `go_jail`；`seize_tile:"take"` 与
   `"swap"` 分开判）。本计划**只动展示映射**（`GameData.CARD_KINDS` / `UIKit.card_palette` /
   `gen_gallery.gd` 的 `KIND_*`），**一行都不许进 `card_kind()` 的函数体**。
   **判据（两重）**：① `tests/chance_test.gd` 既有的那 4 条判定契约断言（`jail_to` 先命中、
   `"swap"` ⇒ move、`force_buy_tile` 压过 `move_steps`）必须保持绿；
   ② **新增** `chance_test._test_card_kind_order_is_frozen()` —— 直接读源码断言那 10 个判定令牌
   **按契约顺序**出现（读源码在 `tests/layout_test.gd` 读 `wheel_view.gd` 已有先例）。
   **每个 Task 的"跑确认绿"都包含它。**
2. **不改 `show_card()` 的签名、不动四个相位常量。** `show_card(deck, kind, text, item_id := "")`
   一字不改（`hud_test` / `chance_test` 用 4 参钉着）；`OUT` / `FLIP` / `HOLD` / `BACK` / `CARD_TIME`
   与 `tick()` 的**相位判据**（`if t < OUT` / `elif t < OUT + FLIP` / …）一字不动，只准在分支内部
   加绘制行（见 T4）。新增的 `BADGE_SIZE` 之类**不是**相位常量，允许加。
3. **那条纠缠的解法**（核心改动，T1）：在 `show_card` 里**三行显式派生家族键**，`deck` 从此
   **只担"标题 / 演出标题"一个角色**；再把 `_deck_back_tex` / `_make_card_art` / `_card_face_back`
   的形参由"标题"改成"家族键"、**删掉 `deck == "机会"` 那个三元判断**、改查家族表。
   **禁止**用 `deck.begins_with("🌀")` 这类"另一种拿标题当键"的判法。
4. **合并配色会让 `图鉴.html` 的 chip 颜色变**（图鉴页与卡面**今天五路全不等**；`card_palette`
   甚至**没有 `info` 键**，靠兜底撞上 `ACCENT`）⇒ **T5 必须重跑 `tools/gen_gallery.gd` 并提交
   `doc/game-design/图鉴.html`**，收尾确认 `git diff --exit-code` 干净。
   **裁决口径（设计稿给的）：以「演出 / 卡面」那套为准** —— 玩家真看到的是卡面，图鉴页是参考手册。
5. **摆拍分支名不许改**：`scripts/dev_tools.gd` 的 `tech` / `techroll` / `abstyle` / `itemreveal` /
   `deckout` / `level` / `hand` / `logopen` / `abshow` / `tilt` / `view2d` / `dollyfar` / `dollynear` /
   `freecam` / `rules` / `pause` / `setpanel` 一律**一个字符都不许改**（多处文档按分支名引用）。
   **新增**卡面相关的分支（本计划：`ckind` / `ckback_item` / `ckback_aberr` / `ckback_chance` /
   `cksweep`）**是允许的**，且要照上面的风格写清楚用法。
6. **`hud_test` 里钉着抽卡演出的那几段**（`show_card` 4 参调用 / `CARD_TIME == OUT+FLIP+HOLD` /
   `is_awaiting_confirm` / `is_confirm_visible` / 收尾后 `_card == null` 且层隐藏 / 三处 `z_index` 比较 /
   **`ItemCard` 节点恰好 1 张**）⇒ **T1~T4 每一步改完都要跑 `tests/hud_test.gd`**，
   **预期：全程绿、一条断言都不用改**（前提是守住约束 2 与"道具卡面前面那张仍是 `ItemCard`、家族痕记
   挂它外面"）。
7. **测试文件里一律"运行期"取 `UIKit` / `DeckReveal`，不许在编译期点它们的类名**
   （本仓**四处已写明**的约定，原话见 `doc/game-design/设计决策留痕.md` §二十三 那一整节、
   `tests/hud_test.gd` / `tests/placard_test.gd` 的文件头、`tests/layout_test.gd` 顶部那几段说明）。
   `--script` 主脚本在 autoload 注册**之前**就编译：一旦在**编译期**点了 `UIKit.`
   （它是 `class_name`、不是 autoload），`ui_kit.gd` 就被拖进同一编译单元，它里面那句
   `Fx.play(...)` 当场 `Identifier not found: Fx` ⇒ **整链编译失败 ⇒ 游戏场景都起不来**；
   表现是**测试跑到超时、日志刷一屏 `Nil` 报错**，与"断言写错了"完全两码事。`DeckReveal` 同理
   （`deck_reveal.gd` 静态引了 `UIKit.card_stylebox`，照样把 `ui_kit.gd` 拽进来）；
   `ItemCard` / `Fx` / `Net` 一并照此办。
   **两条可行写法（都是本仓既有先例，照抄，别自创）**：
   ① 有实例就**拿实例读常量** —— `g.deck_reveal.CARD_TIME` / `dr.OUT + dr.FLIP`
     （`hud_test` 里那三条相位钉子就是这么写的）；**本计划 T1 / T2 / T4 新增断言里所有
     `DeckReveal.*` 一律改成这个写法**；
   ② 没有实例就**运行期 `load` 出脚本对象** —— `var UK = load("res://scripts/ui_kit.gd")`，
     然后 `UK.GOOD` / `UK.ACCENT` / `UK.tex(...)`（`hud_test` 里 `UK.ACCENT` 就是这么用的）。
     要读常量表还可 `load("res://scripts/xxx.gd").get_script_constant_map()`（`placard_test` 先例）。
   **唯一可以静态点的**是 `GameData`（纯数据 `class_name`、不引任何 autoload —— `chance_test` 一直
   这么用）⇒ 本计划两张展示表 `GameData.CARD_FAMILIES` / `CARD_KINDS` 照旧静态引用。
   **判据（实跑）**：T1 / T2 / T4 三步新增的测试（`_test_card_style` / `_test_card_face` /
   `_test_card_anim`）在各自 **Step 7 / Step 6 / Step 5 的"预期（全绿）"那一刻必须真的全绿** ——
   改之前这三条**永远到不了**（静态引 `UIKit.` / `DeckReveal.` ⇒ 编译期就断）。
   另：**任何一步的日志里都不许出现 `Identifier not found: Fx`**（出现即踩了本约束）。
   （Step 2 那种"表还没建 ⇒ 整段 `PARSE FAIL`"是**另一个原因**，两码事，别混。）

**两条实测坑（摆拍必备，别踩第二次）：**

- **`itemreveal` 那一段会无条件快进到 `CARD_TIME`**（`g.deck_reveal.tick(DeckReveal.CARD_TIME + 0.01)`），
  而 `deckout` 的"不快进"只保护它自己那一段（门写着 `if not path.contains("deckout")`）
  ⇒ **`deckout + itemreveal` 拍到的仍是正面**。**卡背只有 `deckout` 拍得到**（0.06s / 0.16s 两帧）。
- **摆拍三不许**：**不能加 `--headless`**（无头模式 `get_viewport().get_texture()` 是空帧）；
  **`--` 分隔符不能漏**（这些开关读 `OS.get_cmdline_user_args()`，写成 `--path . --shot=x.png`
  会被 Godot 自己吃掉：不报错、也不生效，日志里一个字都不提）；**文件名决定摆拍内容**
  （`take_shot` 里按 `path.contains(...)` 分支；出图门是
  `not path.contains("plain") or path.contains("card")` ⇒ 想拍到卡，文件名**要么不含 `plain`、
  要么含 `card`**，有其一即可）。
  另：**三帧连拍落在 0.6 / 1.2 / 1.8 s**，**挑第 2 或第 3 帧看**（第 1 帧可能还在 `OUT` 相位）；
  **单跑一次 3~7 分钟**（`--rounds=6` 的房主要等自己的决定窗口），**机器上还有别的 Godot 在跑时别拍**
  （会和 `--import` / 其它测试抢资源，慢到以为卡死）。

**分化表（谁长什么样）**

| | 机会卡（文字卡） | 畸变卡（文字卡） | 道具卡面 |
|---|---|---|---|
| 卡背 | 绿家族 | 紫家族 | 蓝家族 |
| 正面外框 / 标题 / 分隔线 | **绿家族**（原来是卡型色） | **紫家族** | 品质色（`ItemCard` 既有语言，**不动**）+ **外面一圈家族色外发光** |
| 左上徽章 | 🎲 家族（圆，`bs ≈ 36`） | 🌀 家族（圆） | `ItemCard` 自己的 ⚡ / 被动（**不动、不叠**） |
| 右上徽章 | 卡型（图标 + 中文 + 色，**胶囊**） | **不画**（见下） | `ItemCard` 自己的 一次性 / ⏳计数（**不动、不叠**） |

> **畸变的右上徽章为什么不画**：畸变公告那一路 `kind` 恒为 `"aberr"`、不在 `card_kind()` 的五类里，
> 它**没有"卡型"这一维**；家族徽章 🌀 已经说明它是畸变族。设计稿 §3.2 给畸变写的那枚 🚨
> 是把查寝那行抄了过来（🚨 是 `jail` 的图标），照抄会在畸变卡上画一个"查寝"，**是明确的错话**。
> ⇒ 这一处**有意不采纳**，理由写进 T6 的 `设计决策留痕.md`。

**那条纠缠（本计划的核心）**

```
show_card(deck, kind, text, item_id)
      │
      ├─ item_id != ""   → family = "item"      （道具卡 / 失物招领那道道具卡面）
      ├─ kind == "aberr" → family = "aberr"     （畸变公告：deck = "🌀 畸变 · 名"）
      └─ 否则            → family = "chance"    （机会卡：deck = "机会"）
                                  ↓
      family 只喂三处：卡背（底色 / 描边 / 光晕 / SVH / 色调）、正面外框+标题+分隔线、左上家族徽章
      kind  只喂一处：右上卡型徽章（色 + 图标 + 中文）
      deck  只喂一处：标题文字
```

# 批 1 · 摆拍工具 + 两张表 + 解纠缠（结构批：**正面零视觉变化**，只有道具 / 畸变的卡背按设计变）

> **结束标志**：`load_all` + `chance_test` + `hud_test` 全绿；`card_kind()` 判定顺序的源码钉子绿；
> 机会卡正面与改前基准**逐块相同**（这一步故意不换正面的色，好把"结构改动"和"视觉改动"分开验）；

```gdscript
## 取 `src` 里某个函数的**函数体**那一段（从 `signature` 起到下一个顶层 `func ` 之前）。
## 形参改名的核对要问的是"这个函数**体内**还认不认标题"，得按函数切段 —— 不能全文数子串。
func _body_of(src: String, signature: String) -> String:
	var i0 := src.find(signature)
	if i0 < 0:
		return ""
	var i1 := src.find("\nfunc ", i0 + 1)
	return src.substr(i0, (i1 - i0) if i1 >= 0 else src.length() - i0)
```

```gdscript
	var b := Panel.new()

	b.add_theme_stylebox_override("panel", stylebox(bg, int(side * 0.5), border, 2, 2))
	b.mouse_filter = Control.MOUSE_FILTER_IGNORE

	b.add_theme_stylebox_override("panel", stylebox(bg, int(sz.y * 0.5), border, 2, 2))
	b.mouse_filter = Control.MOUSE_FILTER_IGNORE
```

```gdscript
func _add_card_badges(layer: Control, fam: Dictionary, kind: String) -> void:

	var edge: Color = fam["edge"]
	# 左上 = **家族徽章**（圆，家族色，只有图标）
	var fb := UIKit.badge_round(bs, Color(0.15, 0.17, 0.26), edge)
	fb.name = "card_badge_family"
	fb.position = Vector2(-bs * 0.42, -bs * 0.42)   # 同 `ItemCard._badge` 的落点：约六成在卡内
	layer.add_child(fb)
	var fl := UIKit.label(String(fam["glyph"]), int(bs * 0.42), edge)
	fl.set_anchors_preset(Control.PRESET_FULL_RECT)
	fl.horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER
	fl.vertical_alignment = VERTICAL_ALIGNMENT_CENTER
	fl.mouse_filter = Control.MOUSE_FILTER_IGNORE
	fb.add_child(fl)
	# 右上 = **卡型徽章**（色 + 图标 + 中文三通道）。36px 的**圆**塞不下「🚨 查寝」（4 个字形
	# ≈ 39px）⇒ 用**胶囊**（圆角 = 半高，视觉上仍是同一枚圆角徽章，与 `ItemCard._pill` 同族），
	# `bs` 只约束它的高。这一处与设计稿 §二 A.2 的"圆徽章"略有出入，理由就在上一行。
	var kin: Dictionary = GameData.CARD_KINDS.get(kind, {})

		# 它**没有"卡型"这一维**，家族徽章已经说明是畸变族 ⇒ 不画右徽章。

		return

	var kw := bs * 2.05
	var kb := UIKit.badge_pill(Vector2(kw, bs), Color(0.15, 0.17, 0.26), kc)
	kb.name = "card_badge_kind"
	kb.position = Vector2(CARD_SIZE.x - kw * 0.58, -bs * 0.42)
	layer.add_child(kb)
	var kl := UIKit.label("%s %s" % [kin["glyph"], kin["label"]], int(bs * 0.36), kc)
	kl.set_anchors_preset(Control.PRESET_FULL_RECT)
	kl.horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER
	kl.vertical_alignment = VERTICAL_ALIGNMENT_CENTER
	kl.mouse_filter = Control.MOUSE_FILTER_IGNORE
	kb.add_child(kl)
```

**3c. `tick()`**：整函数换成下面这版（**只多出 5 行带 `←` 注释的绘制调用，判据 / 曲线 / 调用位置一字未动**）：

```gdscript
## 相位推进（`_process` 每帧调；测试与摆拍可直接快进）。
## **2026-10-10 卡面美化只往各分支里加了绘制行**（光扫 / 地面光 / 呼吸偏色）：
## 四段时长、相位判据、`_ease_out_back`、末尾的 `_place()` / `_update_btn()` 一律未动。
func tick(delta: float) -> void:
	if not _showing or _card == null or not is_instance_valid(_card):
		return
	var c: Control = _card
	# 收尾：`request_close()` 之后的 BACK 相位，走完自己收掉
	if _closing:
		_close_t += delta
		var k4 := clampf(_close_t / BACK, 0.0, 1.0)
		c.modulate = Color(1, 1, 1, 1.0 - k4)
		var sc4 := 1.0 - 0.42 * k4
		c.scale = Vector2(sc4, sc4)
		_bob = 0.0
		_ground_alpha(1.0 - k4)          # ← 新增：地面光随 BACK 收回
		if _close_t >= BACK:
			_close()
			return
		_place()
		return
	_t += delta
	var t := _t
	# 光扫每帧先收起来；只有 FLIP 的后半段会重新点亮它（见 `_sync_sweep`）
	if _sweep != null and is_instance_valid(_sweep):
		_sweep.visible = false
	if t < OUT:
		var k: float = _ease_out_back(t / OUT)
		c.scale = Vector2(0.55 + 0.45 * k, 0.55 + 0.45 * k)
		c.rotation = -0.05 * (1.0 - k)
		c.modulate = Color(1, 1, 1, clampf(t / 0.16, 0.0, 1.0))
		_bob = 0.0
		_ground_alpha(clampf(t / 0.16, 0.0, 1.0))   # ← 新增：地面光随 OUT 升起
	elif t < OUT + FLIP:
		var k2 := (t - OUT) / FLIP
		c.rotation = 0.0
		c.scale = Vector2(maxf(1.0 - k2 * 2.0, 0.02), 1.0 + 0.06 * k2)
		if k2 >= 0.5:
			_show_deck_face(false)             # 压到最扁的一瞬换面，看不出来
			var k3 := (k2 - 0.5) * 2.0
			c.scale = Vector2(maxf(k3, 0.02), 1.06 - 0.06 * k3)
		_sync_sweep(k2)                        # ← 新增：翻过面之后扫一道斜向高光
		var flash := 1.0 + 0.4 * (1.0 - absf(k2 * 2.0 - 1.0))   # 换面点附近提亮，模拟翻牌反光
		c.modulate = Color(flash, flash, flash, 1.0)
		_bob = 0.0
	elif t < OUT + FLIP + HOLD:
		var h := t - OUT - FLIP
		c.scale = Vector2.ONE
		c.rotation = 0.0
		_bob = sin(h * 2.4) * 3.0
		c.modulate = _breath_color(h)          # ← 改：呼吸微光偏家族色（幅度仍是 0.03）
	else:
		# 停住等「确定」：姿态与 HOLD 段一字不差（呼吸微光 + 上下浮动），
		# 到点不再自动收 —— 由 `s_card_close`（或超时 / 托管）推 `request_close()`。
		# **换面在这里兜一道**：翻面那一跳藏在 FLIP 分支里（压到最扁的一瞬才换），
		# 只要有一跳的 delta 跨过了整段 FLIP（掉帧 / 摆拍直接 `tick` 快进到这一档），
		# 就永远换不过来、卡背一直亮着。这一步幂等，正常路径上写的是同一个值。
		_show_deck_face(false)
		var h2 := t - OUT - FLIP - HOLD
		c.scale = Vector2.ONE
		c.rotation = 0.0
		_bob = sin(h2 * 2.4) * 3.0
		c.modulate = _breath_color(h2)         # ← 改：同上
	_place()
	_update_btn()
```

**3d. 三个私有函数**（加在 `_ease_out_back` 之后）：

```gdscript
## 翻面光扫：只在 FLIP 的**后半段**（已经翻过面之后）扫一道斜向高光；别的相位一律收起来
##（`tick` 每帧先把它置 false，这里只在后半段重新点亮）。
## 前半段不扫：那时还亮着卡背（满铺格纹），再扫一道光会糊成一片。
func _sync_sweep(k2: float) -> void:
	if _sweep == null or not is_instance_valid(_sweep):
		return
	if k2 < 0.5:
		return
	_sweep.visible = true
	var k := (k2 - 0.5) * 2.0
	_sweep.position.x = -_sweep.size.x + k * (CARD_SIZE.x + _sweep.size.x)

## 家族地面光的强度（0 = 收，1 = 满）。**不改任何相位判据**：只给 `_ground` 写 alpha
##（它自己那层 `modulate` 的 rgb 恒为白，动的只有 a）。
func _ground_alpha(a: float) -> void:
	if _ground == null or not is_instance_valid(_ground):
		return
	var m := _ground.modulate
	_ground.modulate = Color(m.r, m.g, m.b, a)

## 停留 / 停住的**呼吸微光**：幅度仍是 0.03，只是三通道各自微微偏向家族色 ——
## 纯白呼吸时看不出家族，偏一点点就够（`lerp` 系数 0.12；再大卡面文字就发绿 / 发紫了）。
func _breath_color(h: float) -> Color:
	var b := 1.0 + 0.03 * (0.5 + 0.5 * sin(h * 3.2))
	return Color(b * lerpf(1.0, _fam_edge.r, 0.12),
		b * lerpf(1.0, _fam_edge.g, 0.12),
		b * lerpf(1.0, _fam_edge.b, 0.12))
```
