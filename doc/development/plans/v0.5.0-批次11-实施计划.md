# v0.5.0 批次 11 实施计划：小人与房子立体化 + 悬停信息条上屏幕层

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把棋子（小人）与装修房子从"印在桌垫上的平面图案"做成**立在桌上的 3D 薄牌**，并把"悬停小人浮出的信息条"从画布搬到**屏幕层**（因此天然面向镜头）。

**Architecture:** 沿用批次 6/9/10 的规则 —— **有厚度的实物一律搬进 `TableProps`**（转盘轮缘 / 两摞牌堆 / 手牌都这么来的）。棋子与房子各一套**节点池**（只建一次、刷新只改 transform/贴图），棋子动画从 2D `Tween` 改写成 3D（世界坐标 + y 抬升 + 绕自身轴的挤压 + 材质 alpha 做传送）。悬停命中交给 `TableProps.token_hit`（八角逐角投影取包围盒，与 `hand_rect` 同链），由 `TableView3D` 新增的 `on_table_hover` 注入转发给 `game`，信息条挂在屏幕层。

**Tech Stack:** Godot 4.6.2 / GDScript / `gl_compatibility`。

**Spec:** `doc/development/plans/v0.5.0-批次11-设计.md`（本计划实现的就是它）。

## Global Constraints

- **不动玩法逻辑与数值**；**不动任何 `@rpc`**；`s_state` 字段**不加不减**；**不动取景常量**（批次 10 刚定标）。
- **不动**桌垫上印着的东西（格子/格名/价格/色带）与 `tile_screen_pos`（格详情卡的锚点）。
- **不动**四角身家条 / 道具弹窗 / 抽卡演出。
- 新增素材为零 ⇒ `LICENSE` 不动；所有网格**程序化**，贴图只用现有素材（`UIKit.piece_tex` / 烘出的房子纹理）。
- GDScript、**Tab 缩进**、中文注释。持续动画手写 `_process` 相位；一次性过渡用 `Tween`（既有约定）。
- **本机 Godot**：`D:\Godot\Godot_v4.6.2-stable_win64_console.exe`（必须带 `_console`）。
- 命令一律 `--headless --path . --script tests/<x>_test.gd`（**带 `_test` 后缀**；例外 `tests/load_all.gd`）；**改完先跑 `load_all`**；抽检 **grep `SCRIPT ERROR`**。
- 红跑一律 `> 日志 2>&1 &` 后台跑 + 到点停（报错时 `quit()` 不执行、进程会挂住）。
- 截图/`--fps=` **不能加 `--headless`**、必须带 `--` 分隔符。联机回归**同一条命令**（host `&` → `sleep 3` → client），且**别跟套件循环塞进同一条命令**（批次 10 实测）。
- **写任何 `z_index` 前先核对目标层现有 z。** 提交信息用中文、自动提交不推送。

## Task 1: 棋子（小人）+ 光环搬进 3D，动画重写

**Files:** `scripts/table_props.gd`、`scripts/board_view.gd`、`scripts/game.gd`、`tests/layout_test.gd`、`tests/hud_test.gd`

**Interfaces:**
- Consumes: `board_view.tile_pos(idx)` / `board_view.slot_offset(slot)` / `board_view.TILE`（沿用，不另立）、`_t3.canvas_px_to_world`。
- Produces（T3 依赖）：`TableProps.set_tokens(rows: Array) -> void`（每项 `{peer, slot, idx}`）、
  `TableProps.token_hit(canvas_px: Vector2) -> int`（`-1` = 没命中）、
  `TableProps.token_alpha(peer: int) -> float`（传送淡出用的只读量）、
  `TableProps.play_token_move(peer: int, path: Array, step_time: float) -> void`、
  `TableProps.set_token_teleport(peer: int, idx: int) -> void`、
  `TableProps.set_ring(peer: int) -> void`、`TableProps.token_world_pos(peer: int) -> Vector3`。
- 移除：`BoardView` 的 `_tokens` / `_make_token` / `token_world_pos` / `play_move` / `_teleport_anim` /
  `_kill_token_tw` / `set_teleport_target` / `_set_ring` / `_build_ring` / `_ring*`。

- [ ] **Step 1: 写失败测试**（`tests/layout_test.gd` 新增段）
  - 棋子薄牌存在、`BoxMesh.size.y > 0.1`（**有高度，不是平面**）；
  - 顶边比板底更靠远端（**后倾**的可执行定义，同已退场立牌那条）；
  - 位置 = `canvas_px_to_world(tile_pos(idx) + TILE/2 + slot_offset(slot))`（**与印刷图案同一套链**，量世界坐标比）；
  - `token_hit`：在棋子画布落点上命中、在空格上 `-1`、重叠时取**离相机最近**；
  - 光环：`set_ring(peer)` 后环可见且环心在该棋子附近；`set_ring(NO_PEER)` 后不可见。
  `tests/hud_test.gd`：`play_token_move` 期间棋子的世界 y **抬升过**（弧）、结束后回到桌面高度；
  传送期间 `token_alpha` 下过 0。
- [ ] **Step 2: 跑测试确认失败**
- [ ] **Step 3: 在 `table_props.gd` 建棋子薄牌 + 光环**（节点池；薄牌 = `BoxMesh(size=Vector3(w,h,t))`，
  正面贴 `UIKit.piece_tex(slot)`（缺素材退回纯色 `StandardMaterial3D`）；后倾绕 X 负角 25°；
  y 落在桌面上（照手牌那条"卡心抬到近边坐在桌面"的算法）；光环 = `TorusMesh` 压扁，尺寸由
  `board` 报的画布像素半径量真变换换算）。
- [ ] **Step 4: 动画**（`play_token_move` / `set_token_teleport`）：逐格 position 补间 + 每步 y 弧
  （`tween_property` 到抬高的 y 再落回，或 `tween_method` 算弧）+ 绕自身轴挤压 scale；
  `Fx.play("tick")` 保留；传送：材质切 ALPHA → alpha 到 0 → 瞬移 → alpha 回 1 → **切回不透明**。
- [ ] **Step 5: 接线 + 删旧段**：`game` 的 `s_move` → `table_props.play_token_move`；`render()` 不再建 2D 棋子；
  `board_view` 删 Step 的 Interfaces 里那批（**保留** `tile_pos` / `slot_offset` / `tile_screen_pos`）；
  `game` 里 `board.token_screen_pos` 的消费点（飘字/飞钞）改走 `table_props.token_world_pos` → 屏幕。
- [ ] **Step 6: 跑测试 + 出图**（3D 端近景 `freecam`：小人立着；2D 端看得见一块面）
- [ ] **Step 7: 提交**
