# 道具重构 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把道具品质从五档（白/绿/蓝/紫/橙）重构为四档（白/蓝/紫/金），把「人为权重抽品质」换成「全池等概率」，并逐件重排 68 件道具的档位与数值。

**Architecture:** 不动任何效果实现的原语结构，只做三件事：① 换品质键名（常量表 + 68 件 `quality` 字段 + 全仓库引用点）；② 把「先按权重定档、再档内等概率取件」塌成「直接在可获取池里等概率取件」，档位限定（黑市=紫/金、科技/畸变=写死档）作为**定位**保留；③ 逐件改数据表的数字与少数机制开关。稀有度门闸从「概率」整体搬到「价格 + 刷新价 + 黑市地皮价」。

**Tech Stack:** Godot 4.6 / GDScript（Tab 缩进、中文注释、静态类型）；headless 测试 `tests/*.gd`；图鉴生成器 `tools/gen_gallery.gd`；Twemoji 14.0.2 → 256px PNG 烘焙管线。

**Spec:** `doc/development/plans/道具重构.md`（已批准；**该文件随本版本合入 `main` 后删除**，逐件最终落点是 `doc/game-design/道具图鉴.md`）

**分支**：当前 `feature/0.15.0`（已开，直接在其上做，不再新建）。

## Global Constraints

- **房主权威**：玩法逻辑只在 host 侧（`scripts/game.gd`）；客户端只发 `c_*` 请求 + 渲染，绝不直接改 `hp` / `htiles`。
- **RPC 命名**：`s_*` = 房主→全员（`authority`,`call_local`）；`c_*` = 客户端→房主（`any_peer`）。私密信息走 `rpc_id`（**唯一例外**：`s_peek_card` 是广播 + 收端自过滤，别改）。
- **状态同步**：任何「全员可见」的状态必须进 `_broadcast_state`。
- **哨兵值**：`GameData.NO_OWNER = -100`（无主地产）、`GameData.NO_PEER = -9999`（无玩家 / 没命中）。**不要用 −1**（机器人 peer 从 −1 编号）。
- **风格**：Tab 缩进、中文注释、`var x := ...` / `: int` 静态类型；持续动画手写 `_process` 相位。
- **测试纪律**（`AGENTS.md` §三）：改完任何 `.gd` **先跑 `load_all`**（很便宜）；再跑**与改动面相关的那几套**，不要每次跑全套。全套留给本批收尾与发版前。
- **改了 `item_data.gd` 的 `ITEMS` 或 `道具图鉴.md`** ⇒ **必须重跑 `tools/gen_gallery.gd`** 并一并提交 `doc/game-design/图鉴.html`（CI 有 `git diff --exit-code` 闸）。**不要手改** `图鉴.html`（生成产物）。
- **数据/文档三处同源**（N6）：道具的字段变更要同时落 **`scripts/item_data.gd`（字段）** + **`tools/gen_gallery.gd`（渲染分支，若该字段要上图鉴）** + **`doc/game-design/道具图鉴.md`（逐件台账）**。生成器会打印三类缺项，收尾时必须是「无缺项」。
- **提交**：中文提交信息、说清「做了什么 + 为什么」；**不推送**、**不打 tag**（等用户明确要求合并/推送时再处理）。

## 品质四档（2026-10-10 道具重构）：**件数分布就是稀有度曲线**，件数与严格递减是硬契约。
func _test_quality_tiers(_g) -> void:
	print("== 品质四档分布 ==")
	_check(ItemData.QUALITIES == ["白", "蓝", "紫", "金"], "四档（实得 %s）" % str(ItemData.QUALITIES))
	_check(not ItemData.QUALITY_NAMES.has("绿") and not ItemData.QUALITY_NAMES.has("橙"),
		"旧键「绿」「橙」已从显示名表退场")
	var cnt := {"白": 0, "蓝": 0, "紫": 0, "金": 0}
	var stray: Array = []
	for id in ItemData.ITEMS:
		var q := String(ItemData.ITEMS[id].get("quality", ""))
		if cnt.has(q):
			cnt[q] += 1
		else:
			stray.append("%s=%s" % [id, q])
	_check(stray.is_empty(), "68 件的品质键全在四档内（越界：%s）" % ", ".join(stray))
	_check(cnt["白"] == 27 and cnt["蓝"] == 20 and cnt["紫"] == 16 and cnt["金"] == 5,
		"件数 白27 / 蓝20 / 紫16 / 金5（实得 %d/%d/%d/%d）" % [cnt["白"], cnt["蓝"], cnt["紫"], cnt["金"]])
	_check(cnt["白"] > cnt["蓝"] and cnt["蓝"] > cnt["紫"] and cnt["紫"] > cnt["金"],
		"白 > 蓝 > 紫 > 金（严格递减）")
	for q in ItemData.QUALITIES:
		_check(ItemData.QUALITY_PRICES.has(q) and ItemData.QUALITY_COLORS.has(q),
			"%s 档在定价表与配色表里都有" % q)
