# v0.5.0 批次 5 实施计划：对手立牌 + 屏幕层信息重排

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把四个玩家的**座位卡从 2D 画布上搬下来，变成桌上的 3D 立牌**（有厚度、向后倾、带投影），并把随之空出来的近场与屏幕层重新排一遍：**手牌放大并下移**、**四角身家条**接管"一眼看谁领先"、**批次 2 推迟的"棋盘铺满桌面"**随座位栏离开画布一并解决。

**Architecture:** 立牌住在 `TableProps` 的 `standees` 子层里（与轮缘/筹码/手牌同一套桌垫 UV 坐标系）；文字用 `Label3D`（设计稿 §五 反转第 4 条已放宽"桌上允许出现可辨认的短标签"）。座位卡离开画布后，`TEX_WINDOW_PX` 从"整张画布"收到**棋盘区域**，桌面平面放大并在外圈铺木纹 ⇒ 观感变成"印在木桌上的一块桌垫"。点击分两路：立牌命中经 `on_table_click` 转给**既有的** `_on_seat_clicked(peer)`（选目标链路一行不改）。

**Tech Stack:** Godot 4.6.2 / GDScript / `gl_compatibility`（实时阴影可用，无 SSAO/景深）。

**Spec:** `doc/development/plans/v0.5.0-桌面实体化-设计.md` §三（座位卡 → 桌上立牌、四角身家条）、§九 补记 2（比例目标解锁）、§六 批次 5；决策留痕 `doc/game-design/设计决策留痕.md` §五/§六。

## 已拍的设计决策（本批次内不再重议）

| 决策点 | 取值 | 理由 |
|---|---|---|
| 立牌形态 | 薄板 `BoxMesh`，**向后倾 ≈25°** | 2D 端近正俯视，直立薄板从上方只剩一条线；后倾才能两端都看得见（设计稿 §九 补记 3） |
| 立牌文字 | `Label3D`（名字 / 身家 / 倒计时） | 设计稿 §五 反转第 4 条已放宽"桌上允许可辨认的短标签"；`Label3D` 比"每块立牌一个 SubViewport"省一个数量级 |
| 公开背包 | 立牌上一排**小卡**（品质色 + 件数 `Label3D`） | 座位卡牌位拆掉后，这是"背包对所有人公开"（留痕 §三 6）唯一能回来的地方 |
| 自己的立牌 | `view_t < 0.5` **隐藏** | 设计稿 §三：第一人称看不见自己；显式隐藏免得它卡在画面边缘露出半个 |
| 操作倒计时 | 立牌上 `Label3D` + 一条细进度条 | 原设计（留痕 §四）是"嵌在当前行动者座位卡里"，这条不改，只换载体 |
| 四角身家条 | **取代**右侧名册栏 | 两者都挂"名次 + 名字 + 身家"，同时留着是重复；设计稿 §三 的"屏幕清理"与参考（骗子酒馆四角角标）都指向只留四角。**代价：右侧名册栏连同它的"地产 ×n · 道具 n / 现金"一起消失** |
| 桌面与桌垫 | 裁 `TEX_WINDOW_PX` 到棋盘区 + **放大桌面平面** + 外圈铺木纹（第二个平面） | 批次 2 的 T4c 把这条推迟到"座位栏换成立牌之时"（设计稿 §九 补记 2）；画布不再需要容纳座位栏 |
| 牌垫阶段按钮 | **改址**：从 `_make_seat` 里搬出来，直接画进画布（不依赖座位卡） | 座位卡一拆，出牌的确认按钮（`_on_use_pressed` 的唯一落点）会跟着没——**这是本批次最容易踩的坑** |
