# v0.5.0 批次 4 实施计划：双视角（滚轮连续推移）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「一个固定俯角」变成**沿一条轨道连续推移的两种视角**——滚轮往前推到接近正俯视的 **2D 桌面**（只看地图、手里没牌），往后拉回 **3D 第一人称**（手里有牌、能出牌）。**取消**批次 2 的相机推拉（`dolly`）。

**Architecture:** `TableView3D` 新增一个视角量 `view_t ∈ [0,1]`（0 = 3D / 1 = 2D）与一个目标值，滚轮改的是目标值，`_process` 里把当前值平滑逼近目标值，再由它插值出相机的位置。手牌的显示与命中判定都由 `view_t` 驱动（**淡出即点不到**），因此 **`game.gd` 一行都不用改**：`_on_table_click` 只看 `hand_hit`，让它在 2D 端返回 -1 就够了。视角是**纯本地**的，不进 `s_state`、不同步。

**Tech Stack:** Godot 4.6.2 / GDScript / `gl_compatibility`。

**Spec:** `doc/development/plans/v0.5.0-桌面实体化-设计.md` §四（第 2 节 双视角 + 滚轮）、§六 批次 4；反转记录见 `doc/game-design/设计决策留痕.md` §五 第 1 条。

## 已拍的设计决策（本批次内不再重议）

| 决策点 | 取值 | 理由 |
|---|---|---|
| 视角量 | `view_t ∈ [0,1]`，滚轮**每格 ±0.25**（4 格走完） | 设计要求"由滚轮累积量驱动、不是硬切开关" |
| 相机 | 插值**俯角**（50°→88°）**且插值到注视点的 3D 距离**（随之变大） | 只插值角度会让桌面在近俯视下超出画面；必须同时调距离才保持"桌面占满画面" |
| 平滑 | `_process` 里把 `view_t` 向 `view_target` 逼近（指数逼近，帧率无关） | 项目约定：持续动画手写 `_process`，Tween 只用于一次性过渡 |
| 手牌 | 随 `view_t` **淡出**（0.35→0.65 淡完），淡到看不见后 `hand_hit` 返回 -1 | 硬切会"啪"一下很丑；淡出同时天然决定"什么时候点不到" |
| 推拉 | `dolly()` **整个删除**，滚轮改驱动视角 | 设计明写"推拉被视角推移取代" |
| 2D 端的牌垫「使用道具」按钮 | **不动** | 2D 下没选牌，它显示「跳过」；那是合法动作，且藏它要新增一处 BoardView 改动，收益不成比例 |

`scripts/table_3d.gd`：把常量区补上，并把 `_build_camera` 改成走 `_apply_camera()`：

```gdscript
const CAM_TILT_2D_DEG := 88.0    # 2D 端俯角（接近正俯视：只看桌上地图）
const VIEW_DIST_2D := 8.2        # 2D 端「相机到注视点的 3D 距离」（对着出图调）
const VIEW_STEP := 0.25          # 滚轮每格改多少（4 格从 3D 走到 2D）
const VIEW_SNAP := 6.0           # 平滑逼近速率：每秒衰减 e^-6（帧率无关的指数逼近）

## 视角量：0 = 3D 第一人称（50°、手里有牌），1 = 2D 桌面（88°、只看地图）。
var view_t := 0.0
var view_target := 0.0

## 设视角目标（滚轮走这里）。夹到 [0,1]。
func set_view(t: float) -> void:
	view_target = clampf(t, 0.0, 1.0)

## 设目标并立即到位：摆拍与测试用（别在玩法里用，会丢掉平滑）。
func snap_view(t: float) -> void:
	view_target = clampf(t, 0.0, 1.0)
	view_t = view_target
	_apply_camera()

## 按 view_t 摆相机 —— 全文件唯一摆相机的地方。
## 俯角与「到注视点的 3D 距离」一起插值：只插角度的话，桌面在近俯视下会超出画面
## （俯角越大，桌面在屏幕竖直方向上的投影越长：8 格约 sin50°≈6.1 → sin88°≈8.0）。
func _apply_camera() -> void:
	var rad := deg_to_rad(lerpf(CAM_TILT_DEG, CAM_TILT_2D_DEG, view_t))
	var d3d := lerpf(CAM_DIST / cos(deg_to_rad(CAM_TILT_DEG)), VIEW_DIST_2D, view_t)
	camera.global_position = Vector3(0.0, d3d * sin(rad), d3d * cos(rad))
	camera.look_at(Vector3.ZERO, Vector3.UP)

func _process(delta: float) -> void:
	if is_equal_approx(view_t, view_target):
		return
	# 帧率无关的指数逼近：每帧把剩余差距衰减 e^(-VIEW_SNAP*delta)
	view_t = lerpf(view_target, view_t, exp(-VIEW_SNAP * delta))
	if absf(view_t - view_target) < 0.001:
		view_t = view_target
	_apply_camera()
```

`_build_camera()` 改成：建相机、设 fov、`add_child`、`camera.current = true`，最后调 `_apply_camera()`（**不要**再手写 `look_at_from_position` —— `_init` 阶段节点尚未入树，`look_at` 会报错，所以 `_apply_camera` 里必须用 `global_position` + `look_at`，而 `_build_camera` 里 `camera` 刚 `add_child` 完就调它是安全的）。

> **注意**：`_process` 里用 `camera.global_position` 要求相机已在树里。`_init` 里 `add_child(camera)` 之后相机就在 `self` 这棵子树里了，`global_position` 可用（与既有 `screen_to_uv` 同一前提）。

```gdscript
const HAND_FADE_LO := 0.35      # 视角量的 0.35 起开始淡出
const HAND_FADE_HI := 0.65      # 到 0.65 淡完（≈0）
const HAND_HIT_MIN_ALPHA := 0.15  # 低于此不再参与命中 —— 「看不见就点不到」

var _view_t := 0.0

## 由 TableView3D 每帧推过来；手牌的显示与命中都只看它。
func set_view_t(t: float) -> void:
	var nt := clampf(t, 0.0, 1.0)
	if is_equal_approx(nt, _view_t):
		return
	_view_t = nt
	_apply_hand_alpha()

## 当前不透明度：3D 端 1，2D 端 0，中间线性过渡。
func hand_alpha() -> float:
	return 1.0 - smoothstep(HAND_FADE_LO, HAND_FADE_HI, _view_t)

func _apply_hand_alpha() -> void:
	var a := hand_alpha()
	var shown := a > 0.02
	_hand_root.visible = _hand_root != null and shown
	if not shown:
		return
	for i in _hand_body_mats.size():
		var m: StandardMaterial3D = _hand_body_mats[i]
		m.transparency = BaseMaterial3D.TRANSPARENCY_ALPHA
		m.albedo_color.a = a
		if i < _hand_face_mats.size():
			var fm: StandardMaterial3D = _hand_face_mats[i]
			fm.transparency = BaseMaterial3D.TRANSPARENCY_ALPHA
			fm.albedo_color.a = a
```

`hand_hit` 开头加一条：

```gdscript
func hand_hit(canvas_px: Vector2) -> int:
	if hand_alpha() < HAND_HIT_MIN_ALPHA:
		return -1     # 看不见就点不到（2D 端出牌要回 3D）
	for i in hand_count():
		if hand_rect(i).has_point(canvas_px):
			return i
	return -1
```

`set_hand` 末尾调一次 `_apply_hand_alpha()`（重建节点后要把当前透明度重新贴上去）。

`scripts/table_3d.gd` 的 `_process` 里，**在 `_apply_camera()` 之后**把视角推给物件层：

```gdscript
	if table_props != null:
		table_props.set_view_t(view_t)
```

（`_process` 的早退分支也要推一次：`view_t` 不变时手牌不需要更新，所以早退是安全 —— 但 `set_hand` 重建后要自己贴，见上。）
