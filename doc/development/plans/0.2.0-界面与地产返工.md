| # | 改动 | 口径 |

| ⑤ | 转盘数字位置 | 根因：`draw_set_transform` 的原点已含盘心，`draw_string` 的位置又加了一次 → 数字落到盘外。已修，并把数字从贴外圈调到扇区中段 |

| ⑥ | 战报 | 默认**收起**；消息在**屏幕上方弹出**，记录仍照旧保留 |
| ⑦ | 格详情卡 | 加**关闭按钮** |
