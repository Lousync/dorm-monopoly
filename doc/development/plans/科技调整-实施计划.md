# 科技调整 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「开局科技」改名成「科技」（「开局」降为「当前唯一的获得时机」，不再是系统名）；把数据形状从 `p.tech` 单字符串改成 `p.techs` 列表（为将来的中局科技卡铺地基，**本批不实现抽卡**）；做两条平衡改动（`眼尖手快` 重定义并实装、`定期存款` 利率 2% → 1.5%）。

**Architecture:** 不动任何科技效果的实现原语，只做三件事：① 改名（玩家可见文案 + 文档 + 图鉴生成器分节名；**内部标识符一个都不改**）；② 方案 B 结构改造（`_build_hp` 的初始字段、`_has_tech` 的**实现**、新增 `_grant_tech`、快照字段改名改类型、玩家面板单行 → N 行）—— `_has_tech` 的**签名与语义不变**，所以全仓 **54 处调用点一行都不用改**；③ 两条效果改动（都在数据表 + 一处逻辑）。

**Tech Stack:** Godot 4.6 / GDScript（Tab 缩进、中文注释、静态类型）；headless 测试 `tests/*.gd`；图鉴生成器 `tools/gen_gallery.gd`。

**Spec:** `doc/development/plans/科技调整.md`（已批准；**该文件随本版本合入 `main` 后删除**，结论落点是 `doc/game-design/科技.md`）
**事实依据**：只读侦察清单 `.superpowers/sdd/科技调整/recon-现状.md`（**`.superpowers/` 是 superpowers 技能的本机临时产物、已 gitignore，任何新克隆里都不存在**）—— 计划里引它只为说明来源，**不是活引用**。

**分支**：当前 `feature/0.15.0`（已开，直接在其上做，不再新建）。

## Global Constraints

- **房主权威**：玩法逻辑只在 host 侧（`scripts/game.gd`）；客户端只发 `c_*` 请求 + 渲染，绝不直接改 `hp` / `htiles`。
- **RPC 命名**：`s_*` = 房主→全员（`authority`,`call_local`）；`c_*` = 客户端→房主（`any_peer`）。私密信息走 `rpc_id`（**唯一例外**：`s_peek_card` 是广播 + 收端自过滤，别改）。
- **状态同步**：任何「全员可见」的状态必须进 `_broadcast_state`。**本批改了快照里的键名 ⇒ 协议文档同步是硬要求，不是收尾装饰**。
- **哨兵值**：`GameData.NO_OWNER = -100`（无主地产）、`GameData.NO_PEER = -9999`（无玩家 / 没命中）。**不要用 −1**（机器人 peer 从 −1 编号）。
- **风格**：Tab 缩进、中文注释、`var x := ...` / `: int` 静态类型；持续动画手写 `_process` 相位，Tween 只用于一次性过渡。
- **改名禁区（本批最容易顺手改坏的一处）**：`scripts/dev_tools.gd` 的摆拍分支名 **`path.contains("tech")` / `path.contains("techroll")` 一律不许改** —— 多处文档按分支名引用（`AGENTS.md` §三、`开发台账.md` 等），文件名是摆拍的唯一入口。**内部标识符按设计稿 §1.4 的结论「一个都不改」**（`_tech_phase` / `_has_tech` / `_tech_tier` / `tech_on` / `tech_tier` / `TechData.*` 全留）；改名前先 `grep`，不要凭直觉统一。
- **协议文档同步**：`doc/development/联机协议.md` 是**协议面**——本批动了快照字段的**名字与类型**（`players[].tech` → `players[].techs`），该文件的条目说明必须与代码**同一步**改，不许滞后到收尾。
- **测试纪律**（`AGENTS.md` §三）：改完任何 `.gd` **先跑 `load_all`**（很便宜）；再跑**与改动面相关的那几套**，不要每次跑全套。全套留给本批收尾与发版前。
- **改了 `scripts/tech_data.gd` 的 `TECHS` 或 `tools/gen_gallery.gd`** ⇒ **必须重跑 `tools/gen_gallery.gd`** 并一并提交 `doc/game-design/图鉴.html`（CI 有「重新生成后 `git diff --exit-code`」那道闸）。**不要手改** `图鉴.html`（生成产物）。
- **提交**：中文提交信息、说清「做了什么 + 为什么」；**不推送**、**不打 tag**（等用户明确要求合并/推送时再处理）。
- **本批不扩协议面**：不加新 RPC、不加新交互窗（中局科技卡才是引入新交互的正确时机）。

	var d := TechData.def(name)
	if d.is_empty() or not bool(d.get("implemented", false)):
