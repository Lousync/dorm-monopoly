# 机会卡改造 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「机会/命运」两套事件卡统一成一套「机会」格 + 三类卡（机会 85% / 道具 10% / 畸变 5%），并把机会卡池重设计为 50 张、以智斗为主。

**Architecture:** 沿用现有「一张卡 = 一个字段字典 + `_apply_card` 顺序分派」的架构，新增 15 个效果字段而不是引入 effect 对象（图鉴生成器 `tools/gen_gallery.gd` 复用同一份 `GameData.card_kind()`，改成对象就会多出第二来源）。抽卡改成「先掷类别、再按类别取值」：机会卡走预生成洗牌的统一牌堆，道具卡按品质权重现掷，畸变卡直接从现有畸变池抽一条立即全场生效。选目标复用现有的 `_tgt_stage == "peer"` 状态机，加一个「这次选目标是卡」的判别位。

**Tech Stack:** Godot 4.6 / GDScript（Tab 缩进、中文注释、静态类型）；headless 测试脚本 `tests/*.gd`；图鉴生成器 `tools/gen_gallery.gd`。

**Spec:** `doc/development/plans/机会卡改造.md`（已批准；**该文件随版本删除**，卡表最终落点是 `doc/game-design/机会卡.md`）

## Global Constraints

- **房主权威**：玩法逻辑只在 host 侧（`scripts/game.gd`）；客户端只发 `c_*` 请求 + 渲染，绝不直接改 `hp` / `htiles`。
- **RPC 命名**：`s_*` = 房主→全员（`authority`,`call_local`）；`c_*` = 客户端→房主（`any_peer`）。私密信息走 `rpc_id`。
- **状态同步**：任何「全员可见」的状态必须进 `_broadcast_state`。
- **哨兵值**：`GameData.NO_OWNER = -100`（无主地产）、`GameData.NO_PEER = -9999`（无玩家）。**不要用 −1**（机器人 peer 从 −1 编号）。
- **风格**：Tab 缩进、中文注释、`var x := ...` / `: int` 静态类型。
- **测试纪律**（`AGENTS.md` §三）：改完任何 `.gd` **先跑 `load_all`**（很便宜）；再跑**与改动面相关的那几套**，不要每次跑全套。
- **改了任何一张玩法数据表**（`game_data.gd` 的 `EVENTS` …）或 `道具图鉴.md` ⇒ **必须重跑 `tools/gen_gallery.gd`** 并一并提交（CI 有 `git diff --exit-code` 闸）。
- **不要手改** `doc/game-design/图鉴.html`（生成产物）。
- **提交**：中文提交信息、说清「做了什么 + 为什么」；**不推送**、**不打 tag**（等用户明确要求合并/推送时再处理）。

```gdscript
## 机会牌堆（预生成洗牌、抽完再补洗）——「小抄」要能预览顶张，就必须有稳定牌序。
var _event_deck: Array = []

func _new_event_deck() -> Array:
	var pool := GameData.events_for()
	if not blackshop_enabled:
		pool = pool.filter(func(c: Dictionary) -> bool: return not c.has("enter_blackshop"))
	if not _settings.shop_on:
		pool = pool.filter(func(c: Dictionary) -> bool: return not c.has("enter_shop"))
	if pool.is_empty():
		pool = GameData.events_for()   # 过滤到空则回退全池（口径与改造前一致）
	pool.shuffle()
	return pool

func _draw_chance_card() -> Dictionary:
	if _event_deck.is_empty():
		_event_deck = _new_event_deck()
	return _event_deck.pop_front()

func _peek_event() -> Dictionary:
	if _event_deck.is_empty():
		_event_deck = _new_event_deck()
	return _event_deck[0]

## 这次落在机会格抽到哪一类。畸变总开关为「关」时**只有 5% 那档**并入机会卡（90/10/0），
## 道具卡那 10% 不动（设计稿 §一 边界规则 1）。
func _roll_chance_kind() -> String:
	var r := randf()
	if String(_settings.ab_freq) == "关":
		return "card" if r < GameData.CHANCE_P + GameData.CHANCE_AB_P else "item"
	if r < GameData.CHANCE_P:
		return "card"
	if r < GameData.CHANCE_P + GameData.CHANCE_ITEM_P:
		return "item"
	return "aberr"
```

> 90/10/0 不符。实现者按设计稿做对了并报了上来，此处已改成对的那版。
> 另注：`GameSettings.ab_freq` 的**默认值就是 `"关"`**，所以不开畸变就是 90/10/0。
