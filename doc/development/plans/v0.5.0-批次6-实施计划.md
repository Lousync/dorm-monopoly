# v0.5.0 批次 6 实施计划：房间 + 台灯 + 光源重做 + 牌堆实体化

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给桌子一个**屋子**并让**光**成为观感的主角——近黑的房间里只有一盏**台灯**亮着，四周落进剪影；顺带把最后两处"贴纸"（机会/命运两摞牌堆）也做成实体，并**实测帧率**（设计稿 §八 风险 1 点名要测）。

**Architecture:** 房间 = 纯程序化的**剪影几何**（几个 `BoxMesh` 拼书架/床架 + 墙面），放在桌子周围，**不吃灯就走不进画面**；台灯 = 程序化的灯罩 + 灯杆 + `OmniLight3D`（暖色、带衰减、**唯一**主光源），批次 3 重开的阴影在它身上做衰减与投影。牌堆 = 两摞有厚度的实体，抽卡四段动画跟着从"贴片"改成"从实体摞上抽出"。

**Tech Stack:** Godot 4.6.2 / GDScript / `gl_compatibility`（实时阴影可用，**无 SSAO/SSR/真景深**）。

**Spec:** `doc/development/plans/v0.5.0-桌面实体化-设计.md` §五（3D 物件与房间）、§六 批次 6、§八 风险 1（性能）；决策留痕 `doc/game-design/设计决策留痕.md` §五。

## 已拍的设计决策

| 决策点 | 取值 | 理由 |
|---|---|---|
| 房间 | 近黑 + **剪影**（书架 / 床架 / 墙），程序化 `BoxMesh` | 设计稿 §五 明写"不做真实宿舍房间建模（只做剪影 + 单光源）"；且拿不到外部素材 |
| 光照 | **一盏台灯 = 唯一主光源**（暖色、带衰减），环境光压到很低 | 设计稿 §五「单点暖光 + 四周近黑」；观感主要来自光而不是几何（§一 提炼的第 3 条） |
| 台灯位置 | 桌子**近端偏一侧**，灯臂伸到桌面上方 | 台灯是真实的桌上物，光池落在桌面中央、四周自然衰减；**对着出图调** |
| 阴影 | **主光源投影 + 物件投影**；`gl_compatibility` 下只开这一盏的阴影 | 批次 3 已把 `shadow_enabled` 重开（当时是为了筹码/手牌能投影）；本批把光源换成台灯并调它的范围/衰减 |
| 环境光 | 从现在的 `0.55` 压到很低（近黑），背景色同步压暗 | 现在环境光偏亮，四周不是"近黑" |
| 牌堆 | 两摞**有厚度的实体**（`BoxMesh` 叠几层），**抽卡动画从实体摞上抽出** | 设计稿 §三 把"机会/命运牌堆 → 两摞有厚度的实体"列为新增物件；批次 3 的 自检把它记在批次 6 |
| 帧率 | 本批**必须实测**并把数字写进报告与台账 | 设计稿 §八 风险 1 |

## Task 1: 房间剪影 + 台灯 + 光照与阴影重做

**Files:** `scripts/table_3d.gd`、`tests/layout_test.gd`

**Interfaces:**
- Consumes: 既有 `_build_environment()` / `_build_table()` 里的那盏 `OmniLight3D`。
- Produces：`func _build_room() -> void`（剪影墙 / 书架 / 床架）、`func _build_lamp() -> void`（灯罩 + 灯杆 + `lamp_light: OmniLight3D`）、`const ROOM_*` 与 `const LAMP_*` 常量。
- 不变量：`camera` / `_apply_camera` / `table_mesh` / `props` / 输入映射**一律不动**。

- [ ] **Step 1: 写失败测试**（房间与台灯节点存在；台灯是唯一主光源；环境光能量低于阈值；主光源 `shadow_enabled` 为真且位置在桌面上方；**台灯不在桌面的 UV 窗口内**——它不该挡住棋盘）
- [ ] **Step 2: 跑测试确认失败**

- [ ] **Step 4: 跑测试 + 出图**（`view0` 与 `view2d` 两端各一张：3D 端应看到台灯与四周剪影、光池落在桌面上；2D 端接近正俯视看不出房间是正常的）

## Task 2: 机会/命运牌堆做成实体，抽卡动画跟着调

**Files:** `scripts/table_props.gd`、`scripts/board_view.gd`、`tests/layout_test.gd`

**Interfaces:**
- Consumes: `board.deck_center(deck)`（画布坐标）与 `TEX_WINDOW_PX` 那条换算链。
