# 实施计划：畸变系统（全场事件）

> 来源：2026-10-04 设计拍板（实机试玩后的设计专场，见 `doc/development/开发台账.md` §六 #5）。
> 机制与图鉴唯一来源：`doc/game-design/畸变.md`。**本计划随版本合入 `main` 后连同文件一起删除。**

## 一、已敲定的口径

| 口径 | 结论 |
|---|---|
| 两道闸门 | 闸门一：每回合最多触发 1 条新畸变；闸门二：全场同时最多 1 条持续型「生效中」，生效期间窗口跳过（随机丢弃、条件顺延） |
| 候选挑选 | 条件 > 随机（顺延补发再插队一级），同级图鉴序 + 掷骰；条件型落选进顺延队列（上限 2，超出丢弃），随机型作废重掷 |
| 触发窗口 | 回合开始结算（体力/冷却/香皂/基金）之后、掷轮之前（`game.gd` `_play_turn` 内） |
| 持续回合 | **按玩家回合数计**（2026-10-04 拍板），默认 2，条目 `dur` 可覆盖（诚信考试=1） |
| 奖学金季 | 每名玩家**自己的回合开始** +¥300（2026-10-04 拍板，相当于全局版信托基金） |
| 调休 | 本回合停转（道具阶段照常），**当前玩家自己的下一回合**连掷两次（2026-10-04 拍板） |
| 设置 | 频率「关/低/中/高」（关=总开关）、持续回合基准、条件触发开关；入口=对局内暂停面板（房主可改、客户端只读），大厅入口随「开局设置面板」批次 |
| 表现 | 从简：公告走 `_log`→顶部气泡 + `s_aberr` 震屏；「生效中」为 hud 右上一枚快照驱动小标签；正式横幅/座位卡角标待界面美术重构后升级 |
| 数值占位 | 金融危机 10%/20%、枪打出头鸟门槛 ¥30000/20%、房价崩盘 3 回合、频率 低6%/中12%/高25%，全部集中在 `AberrationData` static var / 条目字段 |

## 三、影响面（核对清单）

- **已知边界**：调休补班在休眠回合推迟到下一个自己的回合（有单测钉住）；拆迁持皂不补抽（待复核）；持续型 mid-game 改 `持续回合` 只影响后续新触发。
- **后续批次**：大厅开局入口（随「开局设置面板」）；正式横幅 + 座位卡角标（随界面美术重构）；数值专场回填（`AberrationData` 占位）；图鉴逐条改版与新增（台账 §六 #5）。
- **回归风险点**：`pause_menu_test` / `settings_ui_test` 已重跑通过（新增设置行未破坏结构断言）；autotest 默认畸变「关」，联机回归不受影响。
