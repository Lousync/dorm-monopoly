# 道具系统设计文档

> 状态：**讨论稿**（实现未开工）。本对话负责玩法逻辑，美术表现归美术对话。
> 更新：2026-09-30 · 道具入表 9 件 + 预留 1 件（园中叶）。

## 一、关键词表（全局共用语义）

| 关键词 | 定义 | 落地方式 |
|---|---|---|
| **发现** | 三选一 | 弹三张卡选择；真人私下收到自己的三选项（私密 RPC），bot 按策略自动选 |
| **休眠** | 你的回合中不能进行任何操作，**被动照常生效** | 强制保守托管一回合：系统代掷转轮、买地一律拒绝、商店自动离开、赌场自动抽牌（复用 AFK 托管机制），被动与自动结算照常 |
| **跳过回合** | 整回合被压制，**被动也不享受** | 现有"转轮 0 原地待命"、监狱反省属此类 |
| **冷却** | 每个道具**各自**的禁用回合数，默认 = 该道具的体力消耗 | 冷却是道具实例的属性，**跟着道具走**（被交换时带走当前冷却） |

## 二、核心规则

### 体力（闪电）
- 每人独立：**初始 3、上限 5**，自己回合开始时 +1。
- 使用主动道具要求 当前体力 ≥ 道具消耗，用后立即扣减。

### 冷却
- 使用消耗 N⚡ 的道具后，该道具进入 **N 回合冷却**（科技可改，上限 5）。
- 回合开始时判定：冷却 >0 则该道具本回合不可用，并 -1。
- 冷却与体力是两条独立闸；与"每回合一次"三闸并列。

### 使用窗口
- **只能在实现"转轮点数结算完成 → 本回合结束"的区间内使用**（含移动、落地结算、商店/黑市/赌场界面期间）——先掷轮，后用道具。
- **每回合限用 1 次**（被动道具不计入）。
- 转轮 0"原地待命"回合也算完成投掷，仍可用道具（默认值，有异议再改）。
- 用道具不占用、不跳过掷轮。
- 选玩家类道具弹玩家列表；选地块类进入点地模式（右键/Esc 取消）。

### 被动道具
- 不耗体力、不进冷却、不占每回合次数，**持有即生效**。
- 可**主动丢弃**（道具栏丢弃按钮 + 二次确认），丢弃后回道具池。

### 唯一性
- **被动道具与橙色道具整局唯一**：铺货/礼物/发现时，已被持有的唯一道具从可获取池排除。
- 丢弃或持有者破产清栏 → **回道具池**，之后可再次上架。
- **一次性橙货用后焚毁**（`consumed_on_use`）：不回池、永久消失；未使用就丢弃的仍回池。

### 背包
- 每人 **5 格**；满格不可购买/收取新道具。

## 三、buff / debuff 标签表（定稿）

每个会施加给玩家的效果在数据里**人工标注**三档，运行时按标签判断；利弊随局面变化，故不做自动判断，标注权在设计者。

| 标签 | 效果 |
|---|---|
| **debuff** | 机会/命运扣钱、后退、送监；缴费格罚款；转轮 0 待命（免疫=免跳过，仅原地不动）；黑市出口费；黑市挨打（半款+休眠）；特殊事件不利项；平均主义；亡牌炸地；焦土捐款（拟，待确认） |
| **无标签** | **畸变科技的全部效果**——白手起家清空起始资金、强身健体自致休眠等，香皂一律挡不住 |
| **中性** | 租金支付、购买、赌场下注、道具消耗——永不免疫，否则正常经济被打穿 |

## 五、橙色子系统（每件橙 = 一个新机制）

> 设计纲领：**橙色模仿炉石橙卡**——每件都有独特机制与强度，改写规则、引入新子系统；紫色只是对现有规则的强力调用（如平均主义）。新橙货入表时主动排查与已有橙货的联动与冲突，摆给设计者知情确认。框架效果分派预留**自定义效果插槽**，不走原语拼装。

| 橙货 | 牵出的子系统 |
|---|---|
| 黑卡 | 购买次数计费器 |
| 空想者的香皂 | buff/debuff 标签系统 + 融化状态机（分段表现：剩余回合驱动；本对话做状态机与占位表现，正式融化贴图素材归美术对话） |
| 蛋蛋节 | 礼物分发系统 + 一次性焚毁字段 |
| 亡牌飞行员coco | **焦土地块状态机**：原定义完整保存；外观换废墟占位+进度条；无归属（不产租、不算垄断）；任何玩家落地自动扣**捐款**累进进度；达标后恢复原功能且**变为无主**；多块焦土独立计时 |
| 园中叶 | 待定，占位 |

### 已知橙货联动（知情确认过）
- 香皂 + 黑市：出口费、挨打双双免疫，皂党进黑市零风险（知情拍板）。
- 香皂 + 亡牌：施放者持皂 = 自己地皮无伤、炸光别人。
- 香皂 vs 畸变：科技效果无标签，皂党照样吃白手起家清资金、强身健体休眠。

## 六、畸变系统（开局科技）

房主开启"畸变"后，发车前每名玩家**独立发现三张科技、选一张**；结果公告全员（公开/私密挂账）。科技池为数据表，可扩展。

| 科技 | 效果 |
|---|---|
| 白手起家 | 起始资金清零（跟随开局设置）→ 发现三张紫道具选一张 → 该道具**冷却值 +1（上限 5）**，并获**自动补充**：每次冷却结束的回合开始时道具自动回格 |
| 强身健体 | 本局道具体力支付一律 -1（下限 1）→ 累计每用 3 次道具，**下一回合休眠**，计数清零；冷却是否随支付一起减：挂账（推荐不减） |

**畸变效果一律无 buff/debuff 标签**，香皂对科技无效。

## 七、特殊事件系统

开启后，host 在某些回合开始时触发**全场事件**，横幅公告+全员角标，持续该回合；触发节奏挂到开局设置讨论。

- **诚信考试**：本回合所有玩家不能使用道具（只封使用；冷却照常计时、自动补充照常到账）。实现为道具闸门之一。注：特殊事件不利项是 debuff，皂党不受封锁。

## 八、黑市与小卖部

### 小卖部（地图格型）
- 新格型 `shop`，落在格上开商店面板；3 栏货架，按品质权重铺货（白 45 / 绿 30 / 蓝 18 / 紫 7 为初始建议）。
- 购买入包（≤5）；已售栏位保持空到有人刷新。
- 刷新价全局递增：¥300 起、+250/次、封顶 ¥2000、整局不重置（待确认）。

### 黑市（仅由机会卡进入，不占地图格）
- 机会卡事件「进入黑市」；开局设置可关闭（关闭=构建卡池时过滤该事件，整局不出现）。
- 货架 3 栏，**紫/橙起步**（紫 70 / 橙 30）。
- **一切消费用地产**：紫 1 块 / 橙 2 块 / 刷新 1 块 / **出口费 1 块**（待确认）。
- 交地由玩家自选（bot 交最便宜）；被收地皮回归无主可再买（推荐，待确认）。
- 付不起地皮（含出口时刻）→ **挨打**：扣当前现金一半（向下取整）+ **小黑屋（休眠一回合）**，被扔出店。带着 0 块地皮进店 = 进店即挨打；带 1 块买完东西 = 出口挨打（界面红字警告）。
- 界面文案统一用「黑市」（原名"黑店"已更名）。

### 机会卡新事件（卡池扩展）
1. `enter_shop` 进入小卖部
2. `gain_item: id` / `gain_item_quality: 品质` 获得道具（背包满则作废提示）
3. `enter_blackshop` 进入黑市

新卡带 `only: "机会"` 标记只在机会格出现（命运格共享卡池）。

## 九、开局设置（框架，细节后续单独讨论）

房主开局前可配置：胜利条件、起始资金、畸变开关、特殊事件开关、**黑市开关**等。规则代码中所有写死常量（起始资金、回合上限等）收拢到设置对象。

## 十、联机与托管

- 全程 host 权威：库存/体力/冷却/货架/刷新价/焦土进度/科技/事件全在 host；客户端发请求（买/刷/用/选目标），host 校验广播。
- 体力与冷却公开显示；**背包建议公开**（别人知道你有亡牌才有博弈；挂账）。
- Bot 全自动：按策略购买/使用/选目标/交地/送礼决策；AFK 超时自动兜底（休眠=强制托管复用此机制）。
- 破产观战者清空道具（唯一道具回池）且不可用。
