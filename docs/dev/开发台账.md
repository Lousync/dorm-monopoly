## 四、文档维护规则

- 机制/数值改动 → 同步对应 `docs/gameplay/*`。
- 协议/架构改动 → 同步 `docs/dev/*`。
- 新想法（未排期）→ 记 `docs/想法备忘.md`。
- 代码注释引用文档一律用**新路径**（`docs/gameplay/...`）。
