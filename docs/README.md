# 文档总索引

> 《宿舍大富翁》文档入口。工程与玩法分两处，**改代码前先看这里对应的一篇**。
> 更新：2026-10-02。

## 我该看哪篇？

| 我是… | 先看 |
|---|---|
| 新加入的开发者 | `dev/上手指南.md` → `dev/架构总览.md` → `dev/联机协议.md` |
| 要改某个玩法 | `gameplay/README.md` 找对应系统 |
| 要接美术/表现 | `gameplay/道具系统.md` §12（卡面规格）、`想法备忘.md` §二/§三 |
| 要排期/分工 | `dev/开发台账.md` |
| 要手动验证某件道具效果 | `dev/道具试验场.md`（原型 `道具试验场-原型.html`） |
| 想知道这版改了什么 | `../CHANGELOG.md` |

## 其他

- `想法备忘.md`：讨论过、认可方向、尚未排期的想法（含「布局待返工」「2.5D 路线」）。
- `布局原型-玩家区与选项菜单.html` / `布局原型-四人围桌.drawio`：**定稿存档（2026-10-01），
  不随实现更新**——原型记录的是当时谈定的交互，**可能与现状不一致**（例如原型里的
  「☰ 选项」按钮后来已改名「⏸ 暂停」）。要写代码请以 `gameplay/*` 与现有实现为准，
  不要把原型当成活的规范去逐条对照。
- `道具试验场-原型.html`：道具试验场（Item Lab）的可交互 HTML 原型（设计见 `dev/道具试验场.md`）。
- 代码注释引用文档一律用 `docs/dev/...` 或 `docs/gameplay/...` 新路径。

## 维护规则

- 机制/数值改动 → 同步对应 `gameplay/*`；协议/架构改动 → 同步 `dev/*`；新想法 → `想法备忘.md`。
- `gameplay/道具图鉴.md` 是逐件道具的**唯一来源**；`道具系统.md` 只讲机制与进度，不重复逐件表。
