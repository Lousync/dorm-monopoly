# 赌场 · 炸弹猫

> 地图格型 `casino`（2 格）。逻辑在 `game.gd:_run_casino / _casino_*`，表现由 `board_view.update_casino` + 屏幕弹层承载。
> 更新：2026-10-02。

## 一、触发与注码

- 落到「宿舍赌场」格 → **全员下注**（`CASINO_STAKE=800`，按各自现金封顶）→ 奖池 = 所付之和（**赢家通吃**）。
- 存活 <2 人时不开局，直接离开。

## 二、炸弹猫流程

- 牌堆 `_bombcat_deck()`（12 张）：**炸弹 ×3 / 拆除 ×2 / 小鱼 ×7**（洗牌）。
- 轮流出牌：
  - 抽**牌堆顶**或**牌堆底**；
  - 抽到**炸弹**：若有「拆除」则消耗一张化解，否则**出局**；
  - 抽到**拆除**：收入手中，可抵消一次炸弹；
  - 抽到**小鱼**：无效果。
- **最后存活者**通吃奖池（`s_casino_end`）。
- 单人思考超时默认抽顶（托管）。

## 三、透视（私密信息）

- 每人限一次「偷看牌堆顶」：走**私密 RPC**（`s_casino_peek` 只发给该玩家），符合「私人信息永远走屏幕私弹」的红线（`想法备忘.md`）。

## 四、表现分层

- **桌面设施**：绿呢牌桌 + 金色滚边 + 卡背，常驻显示奖池与状态行（公共信息）。
- **玩法弹层**：`_casino_layer` 全屏进行交互（迁移到桌面面板的时机**待排期**）。
- 同步点：`s_casino_start / s_casino_turn / s_casino_event / s_casino_end`。
