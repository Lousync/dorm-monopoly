# 开局设置（房主配置）

> **状态：设计稿（仅 B 组「操作限时挡位」已实现，见 §三之一）**。入口：房主在大厅点「开始游戏」前弹出**游戏设置**面板；确认后随开局同步**全体（客户端只读展示）**。
> 目标：把散落在 `GameData` / `ItemData` / `game.gd` 里的**写死常量收拢为「设置对象」**（AGENTS 要求），并给房主可控项。
> 关联：`经济与胜负.md`、`回合与行动.md`、`小卖部.md`、`黑市.md`、`赌场-炸弹猫.md`、`开局科技.md`、`畸变.md`、`道具系统.md`。
> 更新：2026-10-02。

## 一、通用原则

- **房主权威**：设置由房主配置，开局时下发；客户端**只读**。
- **默认值 = 当前常量**：不配置即等于现状（保证回归可复现）。
- **收拢常量**：规则代码只读设置对象，不再直接读 `GameData.START_MONEY` 等。
- **校验与预设**：每项有 min/max，越界钳制；顶部提供**预设方案**一键填。
- **下发**：设置进开局 RPC（随 `s_state` 或专门 `s_settings`），客户端展示（面板/战报头部）。

### 三之一 ·「操作限时挡位」细则（已实现）

> 原文「操作时间倍率 ×1.0（0.5~3）」方案**作废**：改为**绝对挡位**，语义更直白（房主直接说「每人 30 秒」）。

- **取值**：共 5 档。
  - `现状`（默认）= 各环节沿用原常量：掷轮 `ROLL_TIMEOUT 35s`、买地/升级决策 `PROMPT_TIMEOUT 25s`、道具阶段 `ITEM_TIMEOUT 12s`、逛店/黑市 `SHOP_TIMEOUT`/`BLACK_TIMEOUT 20s`。
  - `15s` / `30s` / `60s` = 上述**每个环节各自**取该秒数（不是整回合共享预算）。
  - `不限时` = 不计时、**不自动兜底**；真人挂机会真的停在该回合（已确认接受此风险，靠现有退房/终止对局处理）。
  - 未知/非法值一律回落 `现状`（与 §一「默认值 = 当前常量」一致）。
- **生效时机**：改挡位**立即生效并重计时**——当前正在跑的等待按新值重新开始。
- **配置入口（两处）**：
  1. **大厅**：房主点「开始游戏！」前弹**极简弹窗**（仅「操作限时」一排 chips + 取消/开始），确认后开局。其余分组骨架本次不搭。
  2. **对局内**：暂停 → 设置面板新增「操作限时」一行；**房主可改、客户端只读**。
  - 客户端在大厅看不到该挡位（入口仅房主可开）；开局后在对局内设置面板可见。
  - **不持久化**到 `user://settings.cfg`，每局重设。
- **下发**：随状态快照 `s_state` 增加 `timeout_tier` 字段（开局与中途改都走这条既有通道），**不新增 RPC**（符合 AGENTS「全员可见状态必须进 `_broadcast_state`」）。
- **表现**：决策弹窗的倒计时进度条按当前挡位重启；`不限时` 档不显示倒计时条。掷轮/逛店环节本无倒计时 UI，不新增。
- **文案**：`rules_text.gd` 里写死的「真人 35 秒不掷」「25 秒不答」改为按本局挡位显示（`不限时` 档显示「不限时」）。
- **代码落点**：新增 `scripts/game_settings.gd`（`class_name GameSettings`，持有 `timeout_tier` + `static func turn_seconds(tier, kind)`）；`net.gd` 加 autoload 字段承载房主配置；`lobby.gd` 面板；`table_hud.gd` 设置行；`game.gd` 统一等待原语 `_await_turn_window()` 接入掷轮/决策/道具/逛店/黑市五处。

## 十、实现要点

- 新建 `GameSettings`（`class_name`，Dictionary 或 `Resource`）：字段覆盖上表；`GameData`/`ItemData` 的常量作为**默认值来源**。
  - **已落地**：目前只有 `timeout_tier` 一个字段 + `turn_seconds()`；后续设置项往同一对象里追加，规则代码逐项改读 `settings.xxx`。
- `game.gd` 全部规则改读 `settings.xxx`，不再读裸常量；`_host_setup()` 接收 settings。
- 大厅（`lobby.gd`）：房主「开始游戏」前弹**设置面板**（预设 chips + 分组折叠 + 高级项）；确认后 `Net.start_game(settings)`。
  - **已落地**：仅极简弹窗（一排「操作限时」chips），分组骨架后置；`Net.start_game()` 签名不变，配置由 `net.gd` 的字段承载。
- 下发：开局 RPC 携带 settings（或进 `s_state`），客户端只读展示（战报头部/设置查看）。
  - **已落地**：走 `s_state.timeout_tier`，开局与中途改共用；客户端在对局内设置面板只读展示。
- 与 **试验场/回归**：设置对象可注入，便于复现（见 `dev/道具试验场.md`）。
- 面板 UI 建议：顶部预设标签，下面「经济 / 节奏 / 胜利 / 道具 / 特殊 / 其他」分组，高级项折叠。
