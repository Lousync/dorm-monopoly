# 特殊事件（全场事件）

> 状态：**设计完成，待实现**（属「开局设置」批次，见 `道具系统.md` 后续批次）。
> 数据源头将是数据表（可扩展）；本表与实现同步。

## 机制

- 开启后，host 在**某些回合开始时**触发**全场事件**：横幅公告 + 全员角标，**持续该回合**。
- 触发节奏挂在**开局设置**上（待「开局设置专场」定稿）。
- **特殊事件的不利项是 debuff**——持皂党不受封锁（与畸变相反）。

- **与香皂**：不利项是 debuff，皂党不被封锁。
- **备注**：与「道具阶段」状态机对接；开启/关闭随开局设置。
