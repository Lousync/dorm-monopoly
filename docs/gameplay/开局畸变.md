# 开局畸变（开局科技）

> 状态：**设计完成，待实现**（属「开局设置」批次，见 `道具系统.md` 后续批次）。
> 数据源头将是数据表（可扩展）；本表与实现同步。

## 机制

- 房主在开局设置里开启「畸变」后，**发车前**每名玩家**独立发现三张科技、选一张**。
- **结果公告全员（公开，定稿）**。
- 科技池为数据表，可扩展。
- **畸变效果一律无 buff/debuff 标签**——香皂对科技无效（持皂党照样吃白手起家清资金、强身健体休眠）。

## 科技图鉴

### 白手起家

- **效果**：起始资金清零（跟随开局设置）→ 发现三张**紫道具**选一张 → 该道具**冷却值 +1（上限 5）**，并获**自动补充**：每次冷却结束的回合开始时，道具自动回格。
- **备注**：牵出「道具自动补充」子系统。

### 强身健体

- **效果**：本局**道具体力支付一律 -1（下限 1）** → 累计每用 3 次道具，**下一回合休眠**，计数清零。
- **定稿**：**冷却不随支付减少**（冷却固定 = 道具基础消耗）。
- **备注**：牵出「道具使用计数 → 休眠」钩子，依赖「休眠」状态机（已在小黑屋落地）。
