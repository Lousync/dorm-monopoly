# 经济与胜负

> 数值源头：`scripts/game_data.gd`；结算逻辑在 `game.gd`。更新：2026-10-02。

## 一、资金

| 项 | 值 | 说明 |
|---|---|---|
| 起始资金 | `START_MONEY=20000` | 每局开局 |
| 工资 | `SALARY=4500` | 踏过/停在起点领取 |
| 强制缴费 | `FINES` 表 | 4 个缴费格，400~1500，逐格固定 |
| 兼职/奖励 | `BONUSES` 表 | 6 个奖励格，400~2000，逐格固定 |

- 罚金/扣钱/后退/送监/请客等**带 debuff 标签**，持「空想者的香皂」可免疫（逐受害者独立）。
- 租金支付、购买、赌注、道具消耗为**中性**，永不免疫。

## 二、转轮与反省

- 幸运转轮 0~12（`wheel_view.gd`）：
  - **12**：满值，额外再走一回合。
  - **0**：原地待命一回合。
  - **连续 3 次 ≥10**：兴奋过度，被查寝送宿委会（跳过一回合）。
- 宿委会（`jail` / 角格 17）：`skip=1`，整回合被压制、**被动也不享受**（「跳过回合」语义）。
- 「小黑屋」是另一种惩罚，语义是**休眠**（被动照常、保守托管），见 `黑市.md`。

## 三、破产

- 支付时现金不足 → 玩家出局：`alive=false`、现金清零、名下地产收归无主（`owner=NO_OWNER`、`level=0`）。
- 破产者进入观战。
  > ⚠ **缺口**：设计 §10 要求破产时**清空其道具、唯一道具回池**，当前实现未处理，待补。
  > ⚠ 设计还要求「破产观战者不可用道具」——随该缺口一并补。

## 四、胜负

- **最后存活**：`_check_end` 判定只剩 1 人 → 该玩家胜（全员破产则学校胜）。
- **回合上限**：`MAX_ROUNDS=30`，到达后按**身家**排名结算：
  - 身家 `_net_worth(p)` = 现金 + Σ(地价 + 等级 × 升级费用)。
  - 最富有者胜（`_end_by_wealth`）。
- 结束走 `_end_game`：停表、广播 `phase=ended`，各端展示排名 + 彩带。
