# 小卖部

> 地图格型 `shop`，共 **4 家**（由机会/命运格腾位）。逻辑在 `game.gd:_run_shop / _shop_*`，表现/货架在 `board_view.gd:_make_shop / set_shop_display`。
> 更新：2026-10-02。

## 一、进店

- **落在地图小卖部格**即进店（不进则无事）。
- 每家店**独立 3 栏货架**（`shops[tile_idx] = {slots:[id×3]}`）。
- 桌面上的小卖部**设施**公开显示货架卡面 + 价格（全桌可见）；**操作条只给行动者**（屏幕底部居中）。
- 行动者 20 秒无操作 → 被请出（`SHOP_TIMEOUT=20`）。

## 二、货架与铺货

- **品质权重** `SHOP_WEIGHTS`：白 40 / 绿 30 / 蓝 20 / 紫 5 / **橙 5**。
  - 橙池空时该份额并入紫（`_stock_one`）。
  - ⚠ 权重必须是**运行时可变状态**（预告有道具/畸变改刷新概率），不可写死。
- 售价 `QUALITY_PRICES`（占位，待数值专场）：白 600 / 绿 1000 / 蓝 1800 / 紫 3000 / 橙 4500。
- 可获取池 `_item_pool(quality)` 排除：**已被持有的唯一道具 + 小卖部在售 + 黑市在售 + 已焚毁**的一次性道具。
- 已售栏位**保持空**，直到有人刷新或有新铺货。

## 三、操作

| 操作 | 规则 |
|---|---|
| 买 | **点桌面上小卖部货架的卡**（营业时卡片可点、显示「点击购买」），或点底部操作条的「买」按钮。扣现金、入包（背包 ≤5）；持**黑卡**且有剩余次数则免单；已售栏清空 |
| 刷新 | 费用 = `REFRESH_BASE 500 + REFRESH_STEP 300 × 全场刷新次数`；**全局递增、整局不重置** |
| 离开 | 结束本次逛店 |

> 交互分层：桌面货架是**公共信息**，营业时**行动者**点它即可买（其他人点了无效，房主只认当前行动者）；底部操作条为备用入口。

## 四、bot 策略

- 买得起的最贵一件（背包留位）→ 然后离开。
