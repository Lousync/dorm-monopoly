# 回合与行动

> 对局主循环的状态机（玩法视角）。实现：`game.gd:_run_game / _play_turn / _resolve_tile`；协议细节见 `docs/dev/联机协议.md`。
> 更新：2026-10-02。

## 一、回合顺序

- 玩家按加入顺序（`hp` 数组）**轮流行动**；破产/出局者被跳过（`_advance_turn`）。
- 所有人各行动一次为**一回合（round）**；`turn_i` 回到 0 时 `round_no += 1`。
- 第 `MAX_ROUNDS=30` 轮结束按身家结算（见 `经济与胜负.md`）。

## 二、一回合两阶段

```
回合开始结算 → ①转轮盘 → 移动 → 落地结算 → ②使用道具 → 回合结束
```

### 回合开始（`_item_turn_start`）

- 体力 +1（上限 5）；道具冷却 -1。
- 香皂融化计数 -1，归零自动丢弃回池。
- 信托基金 +¥100。
- 重置「本回合已用道具」标记。
- 休眠（小黑屋）玩家：以上被动/自动结算**照常**，但本回合强制保守托管。

### ①转轮盘

- 幸运转轮 0~12（`wheel_view.gd`）。
  | 点数 | 结果 |
  |---|---|
  | 1~11 | 前进对应步数 |
  | **12** | 满值，走完后再**额外行动一次** |
  | **0** | 原地待命一回合（仍算完成投掷，之后可用道具） |
  | 连续 3 次 ≥10 | 兴奋过度，被查寝送宿委会（跳过一回合） |
- 作弊器 / 强制点数可指定本次点数（按正常规则结算）。
- 真人超时 `ROLL_TIMEOUT=35s` 由系统代掷。

### 移动与落地结算（`_resolve_tile`）

- 逐格动画（`STEP_TIME`）；途中**踏过起点领工资** `SALARY=4500`。
- 按落点格型结算：买地/升级/收租（`棋盘与地产.md`）、事件卡（`事件卡.md`）、
  缴费/奖励、小卖部（`小卖部.md`）、赌场（`赌场-炸弹猫.md`）、送监。
- 买地/升级是**弹窗询问**（`_ask`，超时 `PROMPT_TIMEOUT=25s` 视为拒绝）。

### ②使用道具（`_item_phase`）

- **每回合限用 1 次**（被动不计入）；有可用道具才进入该阶段。
- 使用窗口 = 转轮结算完成 → 本回合结束（含商店/黑市/赌场期间）。
- 不占用、不跳过掷轮；超时 `ITEM_TIMEOUT=12s` 自动跳过。
- 闸门三道：体力足够、该道具冷却为 0、本回合未用过。
- 休眠玩家跳过该阶段。

## 三、休眠 vs 跳过回合（易混）

| | 跳过回合（skip） | 休眠（sleep，小黑屋） |
|---|---|---|
| 被动/自动结算 | ❌ 不享受 | ✅ 照常 |
| 掷轮 | 整回合不掷 | 系统代掷 |
| 买地/升级 | — | 一律拒绝 |
| 商店 / 赌场 | — | 自动离开 / 自动抽牌 |
| 道具阶段 | — | 跳过 |
| 触发 | 宿委会反省、转轮 0 待命 | 黑市挨打 |

## 四、决策与托管

- `_ask(kind, amount)` 向目标玩家询问（`buy` / `upgrade`）；真人弹窗、机器人按策略、休眠拒绝。
- 超时/掉线 → 系统托管（代掷、代决定、商店/黑市自动处理）；详见 `docs/dev/联机协议.md`。
